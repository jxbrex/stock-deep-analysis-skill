# 财报质量核查（Forensic Accounting）

目的：估值之前先回答一个更基本的问题——**这份利润是不是真的**。
`em_fetch.py` 自动输出「财报可信度初判」（应计比率 + M-Score + 审计意见 → A/B/C/D），
本文件是判定口径与手工核查方法。模型可下调评级，上调必须给证据。
**审计意见的用途**：供 L4 红灯 a 项判定（非标即红灯回避）——已不在 1D 红旗清单，
放 1D 扣 1 分是轻判。

## 1. 应计质量（Sloan 异象）

- **应计比率 = (净利润 − 经营现金流) ÷ 平均总资产**：<0 为优（现金利润超账面利润）；
  0-5% 正常；**>10% 红旗**。应计占比越高，未来回报越差（Sloan 1996）。
- 现金转化率（CFO÷净利润）看 3-5 年趋势：长期 <80% 且持续下滑必须解释；
  利润增长而现金转化恶化是核心风险，不是附注。

## 2. Beneish M-Score（盈余操纵概率，八变量）

`M = −4.84 + 0.92·DSRI + 0.528·GMI + 0.404·AQI + 0.892·SGI + 0.115·DEPI − 0.172·SGAI + 4.679·TATA − 0.327·LVGI`

| 变量 | 含义 | 危险方向 |
|---|---|---|
| DSRI | 应收/收入指数 | ↑ 提前确认收入 |
| GMI | 毛利率指数（旧÷新） | ↑ 毛利率恶化诱发操纵 |
| AQI | 资产质量指数 | ↑ 费用资本化 |
| SGI | 收入增长指数 | ↑ 高增长公司动机更强 |
| DEPI | 折旧率指数 | ↑ 放慢折旧 |
| SGAI | 费用率指数 | ↑ 效率恶化 |
| TATA | 总应计/总资产 | ↑ 权重最大项 |
| LVGI | 杠杆指数 | ↑ 违约压力 |

判读：**M > −1.78 → 可能操纵区**——不是定罪，是移入"逐项手工核查"名单。
**金融/保险/证券股不适用**（资产负债结构不同），改查第 6 节替代项。

## 3. 收入确认红旗（手工核查项）

- DSO 背离：应收增速持续 > 收入增速（连续两年以上）→ 渠道塞货/放宽信用/提前确认。
- 递延收入/合同负债背离（订阅类致命项）：收入加速而合同负债减速 → 增长在透支未来。
- 经销商压货、关联方循环交易、季末突击发货（Q4 占比异常）。
- 重述历史、更换收入确认政策 → 一律建桥，桥不平就是红旗。

## 4. 费用资本化与利润平滑

- capex 长期 > 2× 折旧摊销而资产周转率没有相应提升 → 可能把费用藏进资产负债表。
- 存货细分背离：产成品增速 > 原材料增速 = 需求恶化领先指标。
- 换 CEO 集中"洗大澡"；准备金计提率逆周期波动。
- "非经常性损益"连续 3 年以上出现 → 重分类为经常性，直接调整常态化盈利。

## 5. 治理信号（非量化但权重高）

审计师频繁更换/审计费异常低/内控重大缺陷/非标意见；CFO 或审计委员会主席突然离职；
财报推迟；监管问询函的主题与频率；做空报告指控与公司回应质量；
关联交易定价公允性；A 股另查股权质押与资金占用。

## 6. 行业替代项（金融股不用 M-Score）

**金融股（银行/保险/券商）的财报可信度替代项以 `industry-financials.md` 为唯一权威**
（scoring.md 与 em_fetch.py 均指向该文件）。本文件只列非金融行业替代项：
REIT/地产（AFFO 调整项、资本化利息）、能源（储量重述与折旧口径）。

## 7. 可信度评级（预注册，接入红/黄灯）

| 等级 | 判定 | 对结论的强制作用 |
|---|---|---|
| A | 无红旗；应计 <5%；现金含量健康 | 无限制 |
| B | 应计比率 5-10%，或 M-Score 落在 −2.0 ~ −1.78（脚本阈值 `acc>0.05 或 m>−2.0`） | 无限制，列入监控指标 |
| C | M-Score 越限 / 应计 >10% / 现金含量连续 2 年 <0.7 / 治理红旗 1 项严重 | **黄灯 d 类至少扣 0.5**，00 章必须警示 |
| D | 多项严重叠加 / 涉嫌造假证据 / 审计非标 | **红灯回避**；估值章节注明"可信度恢复前估值仅供参考" |

等级 C/D 时**禁止用"估值便宜"对冲**——便宜是造假最常见的伪装。
