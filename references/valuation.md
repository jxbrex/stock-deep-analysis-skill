# 估值细则（Phase 3 唯一权威 · 价格轨）

> 本文件承接 SKILL.md 的 Phase 3。**估值章必读**：三情景构建、历史时段匹配 PE 校准、
> 三指标提取（中枢期望收益/赔率/离散度）、合理倍数、税后股息、DCF 条件触发、
> 市场预期差三档拆解全部在这里。基准率分位在 `base-rates.md`；WACC 默认 8%（有可靠数据再替换）。
> **估值分是独立轨，不进质量分**——本文件所有内容服务于「估值分」和 7 估值章。

## 估值轨定位（v4.0 关键）

估值回答的唯一问题是：**现在这个价格，相对内在价值是便宜、合理、还是贵。** 它不回答
"公司好不好"（那是质量轨的事）。「好公司太贵」的正确结论是「等」，不是「扣质量分」。

估值分映射见 `scoring.md`（0-10：**≥8 深度安全边际 / 6-7.9 合理偏便宜 / 4-5.9 合理无安全边际 / <4 贵**，与脚本判词唯一口径一致）。
**估值轨拦截器**：中枢期望收益为负（基础中值 < 现价）→ 无论质量分，仓位归「回避当前价格」。

## 三情景构建（由 Phase 0 关键驱动定义）

**外部视角纪律（MANDATORY）**：每个净利/增速关键假设旁标注 base rate 分位
（`base-rates.md`）；落在历史 80 分位以上的假设必须给结构性理由，悲观情景不得好于历史 30 分位事件。

1. **Pessimistic Scenario**: The key negative driver materializes.
2. **Base Scenario**: Most likely path given current information.
3. **Optimistic Scenario**: The key positive driver materializes.

For each scenario:
- **Time horizon（MANDATORY）**：每个情景标注时间维度（默认 12 个月）；不同情景可不同，必须写明——+40%/1年 和 +40%/3年 是完全不同的机会。**写法约定：必须含「年」或「月」单位**（如 "12个月""1年""12-24个月"），脚本按年×12 解析；纯数字按月处理。
- **Net profit range**（年度，附推导）
- **EPS**
- **PE multiple** — 用**历史时段匹配**校准：
  - 找 2-3 个增速/利润规模/宏观背景相似的历史时段，取 PE 区间；
  - 应用「规模折价」：当前利润 >> 历史时，PE 应系统性更低；
  - 写明逻辑："历史时段 X 增速 Y%、PE A-Bx；当前利润 Z× 更大，折价 N% → 校准 PE C-Dx。"
- **Target market cap / price / upside-downside**。

## 市值口径三情景（NAV / rNPV / SOTP 行业附录专用）

地产 NAV、创新药 rNPV、平台互联网 SOTP 等行业方法（见对应行业附录）的估值终点是
**目标总市值**，不是「净利 × PE」：`valuation.scenarios` 每情景用 `"mcap":[低,高]`
（目标总市值，亿元）替代 `profit`+`pe`，目标价 = mcap ÷ shares 由脚本换算
（三情景必须同口径、同情景不得双填——混用/双填/区间非法一律拒渲染）。
三指标（中枢/赔率/离散度）、thesis 一致性校验、估值分四件套公式全部不变。
`valuation_inputs` 加可选 `metric_label`（如 "P/NAV"、"P/rNPV"）替换过程卡 PE(TTM) 标签——
pe_ttm/pe_band 两键数值语义变为对应比率（现价倍数 vs 合理带），合理倍数映射公式不变。
**mcap 推导过程必须完整写在 valuation_html 正文**（NAV 折让假设表 / rNPV 管线表 / SOTP 分部
加总表）——脚本只对终点市值做价格换算；只填 mcap 不写推导 = 违反反幻觉纪律。

## 三指标提取（MANDATORY — 估值轨的核心，不做概率赋值）

**1. 中枢期望收益率**（替代"概率加权期望"）：
```
中枢期望收益 = 基础情景目标价中值 ÷ 现价 − 1
年化中枢收益 = (1 + 中枢期望收益) ^ (1 ÷ 时间年数) − 1
```
基础情景本身就是"最可能路径"，直接用中值作中枢。跨股对比统一用年化中枢。

**2. 赔率**（上行/下行不对称，只需价格）：
```
赔率 = (基础目标价中值 − 现价) ÷ (现价 − 悲观目标价下限)
```
- 悲观下限 > 现价 → 赔率记 `∞`（最强信号，估值分可直接上浮到 ≥8）；
- 基础中值 < 现价 → 中枢为负，触发**估值轨拦截器**（回避当前价格）。

**3. 情景离散度**（不确定性的客观度量）：
```
离散度 = (乐观目标价中值 − 悲观目标价中值) ÷ 现价
```
<30% 可预测 / 30-60% 中不确定 / >60% 高度发散（本质在赌外部变量，仓位降一档）。

**定性概率提示（可选）**：有权威调查/事件日历/隐含波动率等可观测证据时，只定性、不定量。

## 合理倍数（替代机械看 PE 分位）

**目的**：判断「贵不贵」而非「低不低」。高 PE 可能只是因为市场正确地为高 ROIC 持久性定价。

用增长-回报-风险反推合理倍数（戈登/剩余收益简化）：
```
合理 PE ≈ (1 − 再投资率) × (1 + g) ÷ (r − g)
         或
合理 PB ≈ (ROE − g) ÷ (r − g)
```
- 再投资率 = g ÷ ROIC（g 为永续增速，r 为要求回报率/资本成本）；
- 永续增速 g 必须过 base rate 合理性检查，不得 > 长期名义 GDP 增速；
- **对比结论**：现价 PE/PB vs 合理倍数 → 现价是否透支了未来回报。

例：ROE 10%、g≈0%、r=7% → 合理 PB ≈ (10%−0)÷(7%−0) ≈ 1.43x；现价 PB 1.47x → 几乎无折价。

## 税后股息（MANDATORY · 红利股与 A/H 比价必用）

**所有股息率、DDM 折现、A/H 比价，一律用「税后股息」，不用毛股息。** 税率是可配置假设，
标注「以最新税收法规为准」，不同持股主体税率不同（见 `data-sources.md` 港股股息税对照表）。

- A 股个人持股 >1 年：股息红利免税 → 直接用毛股息率；
- 港股通个人持 H 股：约 20%（红筹股约 28%）→ 税后股息率 = 毛股息率 × (1 − 税率)；
- **A/H 溢价必须扣税后再比**：表观 H 股「便宜 37%」，扣税后可能几乎打平。
- **取数**：em_fetch.py E1 直接输出「TTM股息率（税前）」（tushare dividend 实施口径，
  近 12 个月每股派息 ÷ 现价）与「无风险利率（中债10Y）」——`div_yield`/`risk_free`
  优先引用这两个值，税后口径按上文税率折算；取数失败才走手工降级并标估算。

DDM（高股息公用事业/稳定红利）：
```
P = DPS_税后 ÷ (r − g)
```
DPS 用税后、派息率 × 各情景净利推导；r 用无风险利率 + 风险溢价，g 保守（红利股常 0-1.5%）。

## 估值分四件套量化公式（v3.1 · 可复算）

估值分 = **中枢分×40% + 赔率分×25% + 合理倍数分×25% + 股息分×10%**，各子项 0-10：

| 子项 | 评分锚（0-10） |
|------|---------------|
| 中枢分 | ≥+20%→9；+15~20%→8；+10~15%→7；+5~10%→6；0~5%→5；−5~0%→4；−10~−5%→3；<−10%→2 |
| 赔率分 | ∞（悲观仍正收益）→10；≥2→8.5；1.5~2→7.5；1~1.5→6；0.5~1→5；0~0.5→3.5；<0→2 |
| 合理倍数分 | 现价PE ÷ 合理带中值：<0.8→9；0.8~0.9→8；0.9~1.0→7；1.0~1.1→5；1.1~1.2→3.5；>1.2→2 |
| 股息分 | 税后股息率 − 无风险利率：≥3pct→9；2~3→8；1~2→7；0~1→6；−1~0→5；<−1→4 |

**估值分永远由脚本计算（v4.1 起，无手填路径）**：模型只填 `valuation_inputs` 四件套
（pe_ttm / pe_band / div_yield / risk_free）与 `valuation` 结构化三情景，脚本
`compute_valuation_score` 按上表自动算分；fill 里的 `valuation_score` 填了也被脚本计算值覆盖
（差值 >0.11 时告警提示删除）。报告 `valuation_html` 仍须写出四件套计算过程供读者核对
（脚本在第 7 章末尾生成「估值分计算」汇总卡：四件套明细 + 总分行——四件套加权和 = 最终估值分，
判词并入表格，无"脚本生成"类元话术；第 6 章「质量分汇总」只含质量轨明细，估值明细不进第 6 章。
数值以脚本为准）。
**估值分只管「价格 vs 价值」，增长风险、股东回报
趋势等非价格因素一律归质量分（3A）或黄灯（c 类），不得混进估值分**——这是腾讯案例的教训
（把「AI 变现不确定、回购减半」扣进估值分导致 6.5 偏低，应给约 7.6）。

## DCF Anchor (Conditional)

```
If (avg(FCF/NetProfit over 5yr) > 70%) AND (stdev(FCF/NetProfit over 5yr) < 30%):
    → Add DCF as independent anchor；与三情景对照；偏差大则标注原因
Else:
    → Skip DCF
```

**MANDATORY**：DCF 触发条件必须**显式检查并写出结果**——报告里必须写「FCF/净利 5 年均值 X%
（阈值 70%）、标准差 Y%（阈值 30%）→ 满足/不满足 → 执行 DCF / 跳过 DCF」。禁止含糊写「DCF 为锚」
而不执行、不写原因（美的实证：5 年均值约 0.6、标准差巨大，两条都不满足，应明确跳过而非声称用 DCF）。
DCF 表格：预测期 5 年 / 永续增长率 / WACC / DCF 每股价值 / 对应情景。
**capex 口径**：资本开支取不到时，用现金流量表「购建固定资产、无形资产和其他长期资产
支付的现金」替代——em_fetch.py 已在 E3 年表下方「资本开支」行按此口径输出近 3 年值，
FCF = 经营现金流 − 该值，禁止再手工翻年报。

## 市场预期差拆解（MANDATORY — 说明超额收益来源）

估值完成后回答：**你的模型和卖方一致预期的分歧在哪里？** 无预期差 = 无超额收益。
三档输出：A 找到具体卖方假设（对照表）/ B 只有目标价和评级（反推隐含假设）/ C 什么都找不到（只列分歧维度，标"未披露"，禁编造数字）。

拆解完成用一句话总结：本文比卖方更乐观/悲观/一致 + 证伪时的修正方向。
