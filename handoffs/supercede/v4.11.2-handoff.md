## 工单 B：fill-schema 校验去重（66,132 → 62,465 B，-5.5%）

- **删「拒渲染硬校验清单」整节**（原 414-441 行，3.4KB）——该节自称代码校验的
  "全量镜像"，但 v4.11.1 专人同步后审计仍发现 **8 条代码有而文档零提及**
  （分型未填权重告警 / Hero 分位无佐证 / peers 目标点 ROE 量级 / holders 重复
  截止日 / gap_plot 目标价偏差等）——人工双写结构性必漏，镜像制度废止。
- 节位置替换为「拒渲染硬校验（以报错为准）」权威声明：报错文本即完整规范
  （中文、含字段/期望值/实际值/修复指向，6 用例实测自解释）；新增校验只进
  validate.py / scoring.py / render_report.py 报错，不再抄写本文档。
- **字段表 / 细则节 / 骨架节内嵌校验短语瘦身 22 处**（-0.3KB 量级，累计如上）：
  只删"报错能完全兜住"的防御层描述（subtitle 剥离告警 / valuation_score 差值
  告警 / 0.3pct 告警 / 30% 口径告警 / 乱序告警 / 四拍挤段告警 / 40 字阈值 /
  period 超长告警 / best-worst 缺列告警 / 矩阵表删除告警 / 三年并排告警 /
  peers 列支撑告警 / scenario-table 转置告警 / <80 字告警等）；**12 条写作前
  须知全部就地保留**（timing 两维缺一不可 / points 上限语义 / 内容地板字数 /
  fin_trend 3 年 3 面板 / 三情景完整性与口径二选一 / 四件套缺键 + quote 日期
  门禁 / thesis 手写价 2% 口径 / 红灯熔断 / 每表配 .source / peers 必含 table、
  l4 必配 .pm-grid / 【…】用途 / date 与 price 格式）。
- 不可删的硬边界：骨架节（22KB）报错文案 6 处回指其节名（「核心结论四卡骨架」
  「损失预演三联卡骨架」「L4 黄灯扣分明细」等），删节会让报错指针悬空——骨架节

  → 脚本报错）保留。

  thesis 信息量地板（<60 字 / 剥价 <20 字）、【…】只用于黄灯类别标注、
