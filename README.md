# stock-deep-analysis — 个股深度分析技能

基于四层评分框架 + 独立时机轨的个股深度分析技能（Kimi Code / ZCode 通用），
一键取数、脚本拼装，生成单文件 HTML 研究报告。

> ⚠️ 本技能产出的报告为 AI 生成的研究笔记，不构成投资建议。

## 功能

- **三层研究评分 + 时机轨双轨制**：L1 公司本质(50%) / L2 估值(30%) / L3 未来预期(20%)
  共 9 个加权维度；L4 不占权重，改为红/黄灯双层（红灯熔断 + 黄灯扣分）；
  时机分（筹码面 67% + 技术面 33%）独立成轨，只决定建仓节奏
- **股票分型**：周期股 / 稳定价值金融 / 稳健成长 / 快速成长 / 未盈利管线 / 困境反转，
  分型自动调整权重与估值方法
- **三情景估值**：悲观/基础/乐观 + 历史时段匹配 PE 校准 + 年化中枢收益/赔率/离散度三指标；
  报告内自动生成**目标价走廊图**（竖向柱 SVG，脚本计算，模型不手算坐标）
- **回测模式（v3.0）**：同股再分析自动启用——Hero「复盘更新」对比条（分数差值脚本计算）、
  文件名自动加「复盘」、R 回测复盘章节（复盘四格表 + 新财报数据 vs 原假设）、
  变更高亮 `.rev`、10 章首段旧触发条件核对表
- **同业对比**：当前指标表 + 3 年趋势表（文字方向标注）+ **估值-质量散点图**
  （ROE×PE 直角坐标系精确点位，脚本按 `peers_plot` 字段生成 SVG）
- **预期差拆解**：与卖方一致预期的分歧逐项对照（A/B/C 三档降级）
- **盈利质量红旗**：现金含量/应收/存货/毛利率异常/审计意见五项检查（三态标注，禁伪装通过）
- **治理混合制评分**：质押/减持/年龄/处罚量化清单 + ±1 判断调整
- **跟踪仪表盘**：关键指标 + 触发条件；回测模式首段固定为旧触发条件核对表
- **数据获取**：**tushare 优先、东方财富公开 API 自动兜底**双通道（em_fetch.py 内置）：
  行情/K线/财务/股东户数/券商预测/审计意见/主营构成；tushare token 自动发现
  （`TUSHARE_TOKEN` 环境变量 > ZCode config 的 `mcp.servers.tushare.url`），无需手工传入；
  A 股 + 港股（5 位代码自动识别），东财 E7 站内搜索作为无 WebSearch 环境的定性搜索路径
- **妙想 MCP 模型直调层**（可选，东财官方免费 AI 数据服务）：港股财务首选
  （`mx_hk_finance_data`）、定性检索主力（`mx_finance_search_news`/`notice`）、
  大宗商品价格（`mx_macro_data`）

## 目录结构

```
stock-deep-analysis/
├── SKILL.md                    # 技能主体：工作流 + 评分框架 + 数据纪律
├── references/
│   ├── fill-schema.md          # fill→render 工作流的 JSON 契约（报告结构唯一权威）
│   ├── data-sources.md         # 东方财富 API 端点手册 + 港股支持矩阵 + 降级链
│   └── analytical-tips.md      # 历史报告提炼的分析经验（评分/估值时按需加载）
├── scripts/
│   ├── em_fetch.py             # 一键取数（E1-E7 全端点，A股/港股，约 3.5KB/股紧凑摘要）
│   └── render_report.py        # fill JSON → 最终 HTML（评分计算+图形生成+校验+自动命名）
└── assets/
    └── report-template.html    # 报告模板（唯一 CSS 权威版本）
```

## 报告生成流程（fill→render）

1. 调研取数：`python em_fetch.py [代码] --peers=...`（完整输出直接进上下文，禁止 `| tail` 截断）
2. 四层评分 + 三情景估值（分析在主会话完成，禁止委派子代理做定性调研）
3. 写 fill-data JSON（契约见 `references/fill-schema.md`）
4. 渲染：`python render_report.py _fill_[代码].json`
   ——评分汇总表、徽章色、图形 SVG、对齐修正、文件名（`公司名-代码-研究分-时机分-日期.html`）
   全部脚本计算，零拼装 token

## 安装

将 `stock-deep-analysis/` 目录放入技能目录：

- 用户级：`~/.agents/skills/` 或 `~/.zcode/skills/`
- 项目级：`<project>/.agents/skills/` 或 `<project>/.zcode/skills/`

依赖：Python 3.8+、curl（Windows 10+ 自带）；tushare token 可选（无 token 自动走东财公开接口）。
