# 议题一：新第 3 章「最新报告期透视」（季报/中报专属章节）

归因里，写不写全看模型自觉。

## 决议记录（Q1-Q9 终局，不再重议）

- **Q1 触发逻辑**：自适应「最新报告期」——Q1/H1/Q3 均进入本章（Q1 数据重要，
  保留；单薄处标注口径）；最新期恰为年报时（约每年 1-4 月）**整章消失**
  （cycle_html 缺失即删章先例，工程现成）。
- **Q2 位置**：独立新章，插 P0 之后 = **新第 3 章「最新报告期透视」**。原则
  （用户拍板）：呈现与逻辑优先，不向重编号成本妥协。P0 定义第一变量 → 本章
  紧接呈现该变量最新读数，驱动-证据闭环最短；本章服务 P0/3.4/4.1/7/8 多章，
  不归属成长层一家，故独立成章而非 L3 内维度块。原 s3-s13 全部 +1，结论四卡
  锚点映射、fill-schema 与 SKILL.md 全文交叉引用随之改写。
- **Q3 完成进度分母**：公司经营目标（年报「经营计划」段披露，国企/制造业尤多）
  与卖方一致预期（E5）**两者并列、缺一标「未披露」**。卖方营收预测覆盖度低
  （多数券商只给净利+EPS），收入端分母以公司经营目标为主。
- **Q4 指标清单**：只收**绝对额**——收入/净利/扣非/经营现金流（同比+完成进度）。
  **比率一律不进本章**：最新期毛利率变动住 3.3/3.4（v4.10.1 归因三方向）、ROE
  最新期有年化陷阱（E3 已有警告口径）。加**可选「行业专项进度」槽**：地产=合同
  销售额/面积 vs 年度销售目标（月度销售公告有数据）、白酒=合同负债余额变化
  （打款进度代理）、保险=NBV/保费进度——触发与口径写进对应行业附录，不污染
  通用骨架。
- **Q5 评分联动**：**纯描述、零联动**——不进质量分/估值分/时机分，不挂黄灯，
  严禁「进度滞后→扣分」机械规则（季节性公司必然冤案）。进度合理性判定双尺：
  历史同期占比带（自己的节奏）+ 公司经营计划（自己喊的目标）；双尺皆缺标
  「无法判定」——兜底出口，不是缺陷。
- **Q6 单季拆分与季节性基准**：全做、近三年。单季拆分：Q2 单季=H1−Q1、Q3 单季
  =前三季−H1（Q1 期本身即单季，无需拆）；拐点藏在单季，累计口径会滞后一两个
  季度。季节性基准=近三年同期（0630/0930）净利与营收占全年比例带（近两年
  样本太薄，区间不稳）。
- **Q7 呈现形态**：**图为主、文字置底**（≤3 句口径提示，不展开论证——论证各归
  3.4/4.1/8 章）。数据脚本算、判词模型写：进度% 脚本计算并与 E3/E5 落盘交叉
  校验（quote 防伪同款纪律）；判定措辞四选一（超前/正常/滞后/无法判定）由
  模型写、渲染器校验取值合法。图形态溯源 lieflat-charts 词汇：**进度=子弹图**
  （横条=本期累计，两条目标刻度线=公司经营目标/卖方一致预期，底色带=近三年
  同期占比带；F11 Tick Gauge 只承载单值装不下双分母+基准带，弃用；模板 PE
  历史带已是子弹图词汇，风格复用）；**单季=并肩双柱**（F6 Paired Rungs 词汇：
  最新单季 vs 上年同季，同比% 脚本标注；Q1 期退化为单柱）。
- **Q8 年报期退化**：整章消失——年报数据已被 E3 年表、3.4 图墙、1D 红旗完全
  覆盖，保留任何形态都是重复（违反仓库第一纪律）；「一年只存在 8 个月」正是
  「最新边际信息」的定义，不是缺陷。
- **Q9 回测模式**：与普通模式**完全一致**（只写最新一期）。回测最常见触发即
  「新出了一期财报」，本章天然承载该事件；新旧对照全部留 R 章既有机制
  （review_html 对比表 + triggers 状态条），本章不加「进度回测」职能；无新
  财报时（仅股价/原材料价格变动）进度不受影响，本章内容不变，符合事实。

# 议题二：决策层三机制（评分体系两问，终局）

## 背景与定性（已对用户讲清，此处存档）

- **问①（打分漂移+硬边界）定性：噪声问题，非「主观陷阱」**。爆炸半径已被既有
  设计阻尼：跳档只跳相邻档（0/5/10/20 序列），致命门（红灯熔断/中枢为负拦截器）
  先于矩阵执行、不随分数漂移；两位小数是审计链需要（两次 fill 可 diff），不是
  装客观。处方=透明化，不重建。
- **问②（估值分 65% 自我循环）定性：偏差问题，成立**。中枢分 40%+赔率分 25%
  来自模型自填三情景（scoring.md:296 公式已核）。已有六道软约束（base rate
  分位/悲观 30 分位/一致预期扣 3-5pct/预期差三档/pe_band 历史匹配/拦截器不对
  称），失效模式=乐观只需写得出理由。真洞收窄为两个：base 利润无硬绑定、
  赔率∞保送。

## 机制一：临界档透明化（拍板：降档方向）

- 脚本算质量分/估值分距最近边界（质量 7.0/5.5/4.0；估值 8/6/4）的距离，
  ≤0.3 → 判定临界：
  ① 仓位按相邻两档**孰低**执行（降档方向，非抬档）；
  ② 三轨判定卡自动加「档位临界」标注；
  ③ **升档触发条件自动挂第 13 章跟踪仪表盘**（写明复核证据与升档路径——
     「错过」变「推迟+验证路径」，接住抬档派唯一正当诉求）；
  ④ **临界状态下上浮类调节冻结**（时机/离散度/赔率上浮不再生效，下调照常）
     ——防「降一档再浮一档」自我抵消。
- 降档不抬档的三条理由（已辩终局，不再重议）：体系既有设计升难降易（上浮
  封顶 ≤1 档、重仓唯一入口=矩阵直接落位）；噪声叠系统性乐观偏差，边界规则
  须逆向纠偏；买错代价 > 错过代价。
- 阈值 ±0.3 为初始值，实施后按 archive 漂移实测校准。

## 机制二：乐观税门禁

- 脚本机械校验：**base 情景净利 ÷ E5 一致预期净利 > 1.15 → 中枢分封顶 6**
  （估值分随之重算）。
- 唯一解封路径：第 8 章预期差评为 **A 档**（点名卖方假设+出处日期+证伪理由）
  ——「乐观可以，先掏证据」。实现要点：`gap_tier` 为既有必填字段，校验直接
  消费，零新增字段。
- 封顶落在中枢分单项而非总分：其余三项各有自家约束（合理倍数=pe_band 历史带、
  股息=事实、赔率=机制三地板绑定），封顶后即使余项满分，估值分也被压在
  「好价格 ≥8」门槛边沿之下，乐观喊不出「便宜」。
- 阈值 15% 为初始值，实施时按存量报告分布校准。**E5 缺失标的**（无卖方覆盖）
  实施时定，倾向：校验跳过 + 四件套过程卡标注「乐观税未检：无卖方覆盖」，
  base rate 分位软约束照旧——无参照系时不假设乐观也不假设谨慎。

## 机制三：赔率∞收紧（拍板：保留保送但分级）

- 核心修补：**悲观下限数值必须由证据推出**，渲染器机械校验「悲观下限 ≤ 证据
  地板值」——防「温柔悲观+泛泛证据」通关（证据真实但与数字无推导关系 = 安检
  看身份证不查行李）。
- 地板分两档：
  - **硬地板=净现金/股** → ∞ 成立，保留现状全部待遇（赔率分 10、估值分上浮
    ≥8、调节链上浮一档）——「股价低于现金」的 ∞ 是挣来的，接近事实而非判断；
  - **软地板=保底分红折现** → ∞ 成立但保送减半：估值分 +1 封顶 7.5，调节链
    不上浮（分红是政策非担保，深度衰退失灵过——神华 2015 砍分红典故；净现金
    没失灵过）；
  - 无证据 → 悲观下限不许 ≥现价，赔率按有限值正常算。
- scoring.md 三处 ∞ 触点需同步改：赔率分档表（∞→10）、估值分上浮规则
  （「悲观下限>现价→估值分可直接上浮 ≥8」）、决策主轴调节链（赔率 ∞ 上浮一档）。
- fill 契约新增（实施时定名）：情景级地板字段，如
  `{"floor":{"type":"net_cash"|"dividend","value":12.3,"evidence":"净现金123亿÷总股本10亿"}}`，
  渲染器校验悲观下限 ≤ value（容差实施时定）。

## 本轮已辩过、明确不做

- 临界档不抬档（三条不对称理由见上）。
- 不全量双跑取均（方差减半代价 Phase 2 翻倍，噪声不致命，过度工程）。
- 不改估值分权重（语义从「预期收益」变成「现价 vs 历史/股息」，因噎废食）。
- 不做连续仓位函数（把同样的噪声藏得更深）。
- **偏差档案聚合单独立项**：`_archive/_index.jsonl`（v4.10 起）已攒 fill，待
  ≥10 份有兑现结果后做「base 情景 vs 实际兑现」系统性偏差测量——唯一测量
  偏差而非假设偏差的路径；顺带可实测「两次打分漂移 0.5+」论断本身。

## 议题 A：4.0 边界的「一票否决」效应（用户拍板要讨论）

现象：临界带 ±0.3 使质量分 4.0~4.3 实际全部落入「<4 不建议参与」——「质地一般·轻仓 ≤5%」
这一档在边界区失效，4.0~4.3 的分数差异化失去意义。更广义：临界带把每个边界的实质门槛
上移了 0.3（系统性保守倾斜），这是「噪声纠偏」的代价还是隐性加码，值得摆上台面。
讨论方向（不预设结论）：① 4.0 行增设观察池缓冲档（根因是质量 <4 行没有中间档）；
② 临界带只对「从上向下跨边界」生效而非「在带内即降档」；③ ±0.3 按边界差异化
（4.0 收窄或改档型）；④ 维持现状但票面写清。

## 议题 B：同款「点值阈值 + 硬跳档」决策逻辑全排查（机制一的对称作业）

机制一只给分数边界加了临界带，其余阈值仍裸奔。下一轮逐一过，决定哪些值得同款
「临界透明化」、哪些就该硬（红灯熔断设计上即熔断）：

- 中枢为负拦截器（central_raw<0 → 直接回避）：无临界带无缓冲，与 4.0 断崖同构；
- 观察池 → 不建议参与的下调（时机 <4 或离散度 >90%）：观察池本身是缓冲档，下调是直落；
- 上浮冻结的交互强度：5.5 边界 v≥8 临界降 10→5 后，时机 ≥6 也救不回——冻结是否过强；

- 乐观税 1.15：base 净利 1.14x/1.16x 一致预期 = 封顶与否的点值断崖（不直连仓位，烈度低）；
