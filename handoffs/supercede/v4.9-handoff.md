## 改了什么

### 1. 配色系统（`assets/report-template.html` / 图族模块 / `validate.py`）

- `.up`→`#c75b5b`（红）、`.down`→`#6ba86b`（绿）；新增 `.good`（绿）/`.bad`（红）。
  **使用纪律**：方向量（股价涨跌、较现价空间、中枢期望收益）用 up/down；
  好坏评价（赔率、离散度、分数差、龙卷风有利/不利、徽章、散点象限、户数增减、
  哑铃上调/下调）用 good/bad 或保持既有红绿。
- 改挂点：三指标卡赔率/离散度（build_scenario_block）、回测对比条分数差
  （validate.py build_prev_strip）由 up/down → good/bad。
- 顺带审计修复：全站小字灰 `#8a8375`→`#6f695e`（约 3.7:1→5:1）；`danger-card` 底
  `#fdf0f0`→`#f9eeea`（融入暖调）；业务构成图短条占比文字随条色（沙色，2.6:1）→ 深墨。
- **taste-skill 整体配色审计**（用户追加提问）：钢蓝 `#4a6fa5` × 暖象牙纸判定**成立**
  （唯一冷色强调、饱和度 38%、对纸面对比度约 4.7:1，全部保留）；真实问题是 pastel 语义色
  承载白字/小字不达标（绿 2.8:1 / 橙 3.0:1 / 灰 2.2:1）——文字与徽章统一加深系：
  红 `#b84a4a` / 绿 `#4d804d` / 橙 `#96691a` / 灰 `#7a715e`（全 ≥4.5:1），覆盖
  `.up/.down/.mid/.good/.bad`、`.metric-card .value.*`、`badge-*`、`scenario-*`、`flag-*`、
  `.deduction`、估值分大数字 `score-*`，以及评分条 `badge_color` 映射（与徽章同色）。
  SVG 大面积填充（龙卷风条/走廊情景条/散点象限底/户数柱）保留 pastel 原色。
- 新图（fin_trend/growth_plot）**全中性色**（沙/钢蓝/黑），刻意不引涨跌红绿——
  财务指标增速的红绿在双轨语义下必然歧义，干脆不用。

### 2. 新图·fin_trend 财务五年组合图墙（3.4，必填）

- 字段：`fin_trend = {"years":[...], "panels":[{"title","bars":[{"name","unit","values"}, ...≤2条],
  "lines":[{"name","values","pct","threshold"?}, ...≤2条]}, ...≥3]}`；**标准 4 面板**：
  营收×毛利率 / 归母净利×净利率×ROE / 经营现金流+自由现金流×现金含量（阈值0.7) /
  货币资金×短债覆盖率。数据照抄 E3 年表；**自由现金流=经营现金流−资本开支**
  （E3 年表下方「资本开支」行口径）；现金含量=经营现金流净额÷归母净利（scoring.md 1D 口径）。
- 渲染：`.mini-grid` 两列网格（≤768px 折 1 列），每面板=双轴组合图——柱（金额·左轴亿，
  **柱不断轴**；单柱时沙=历史/钢蓝=最新年+同比，双柱并排时沙=第一条/钢蓝=第二条）
  +1-2 线（比率·右轴，首条钢蓝实线/次条灰虚线，首末点标值）+可选红虚线阈值；
  所有小字带 `paint-order` 光晕防柱线叠字（lieflat-charts 语法借用）。
  锚点 `<!--FIN_TREND-->` 挂 l1_html 3.4 块。
- **3.4 禁止再手写 5 年年表**（schema 已改）；有效面板 <3 / 年数 <3 / 缺字段 → 拒渲染
  （`_check_chart_fields` 硬校验）。
- 演变记录：初版 8 格单指标 mini 图（4×2）→ 用户反馈「合并+放大」→ 二轮改组合面板
  （表现形式评估过 lieflat-charts——其交付物为独立 HTML 报告/图页，与本渲染器的内嵌脚本
  SVG 管线不兼容，只借语法不引模板）→ 三轮按用户意见加自由现金流双柱、负债率换成
  短债覆盖率（右轴倍数，>10x 线趋平读作「短债无忧」）。

### 3. 新图·growth_plot 利润增长图（4.1，必填，未盈利/管线豁免）

- 字段：`growth_plot = {"hist":[{"y","rev","np"},...≥3年], "fcst":[{"y","np_lo","np_hi",
  "np_consensus","rev"?}, ...]}`；历史取 E3 同比，一致预期取 E5。
- 渲染：历史段沙柱（收入）+钢蓝柱（净利）并列，零基线；预测段区间竖条（本文 lo-hi）+
  黑◆（一致预期，标签带光晕）+ 组下「差 ±x.xpct」；图例+实际/预测分区虚线；
  画布高 340→288（用户反馈压低）。锚点 `<!--GROWTH-->` 挂 l3_html 4.1 块首；
  `_inject_l3_charts` 新增（render_report L3_HTML 接线）。
- 预期差由脚本算并写进 source 行；第 8 章预期差对照表保留、不重复展开。

### 4. 产业链图纵向均衡（build_chain_plot）

两栏各自在总高 `col_h = rows*(BOX_H+GAP)−GAP` 内均分（`pitch=(col_h−BOX_H)/(n−1)`，
单条居中）；公司卡中心不变。修青啤 4 上游 vs 5 下游顶部对齐下方留白的偏沉观感。

### 5. 业务构成标题怪胎修复（青啤实证）

- 根因：口径清洗说明被塞进 `segments.period`（70 字怪物标题）+ 正文又手写同题引言句。
- 修复：`period` ≤8 字 + 含「口径/源为/合计行/剔除/重算」字样 → validate 告警；
  新增 `segments.note` 渲染为图注「口径备注：」小字；schema 禁止正文再写
  「业务构成（…）」开头的引言句。

### 6. 关键变量命名规范（纯 schema，防「①吨价/产品结构（第一变量）」复发）

p0_html / sensitivity 行新增：变量名单概念（驱动写正文）、黑话白话括注、
正文不重复「（第一变量）」图标签、name ≤12 字。

### 7. DCF 分型双轨（scoring.md「DCF」节重写 + SKILL.md 分型表两行同步）

- 稳健成长/稳定价值（**除银行保险**，走 PB-ROE/DDM）：强制三行——①保守参数 DCF 每股值
  （下界参考，不进估值分权重）②现价隐含永续增速 `g = WACC − FCF₁÷EV`
  （`FCF₁ = 最近年FCF × (1+保守增速)`，`EV = 市值+有息负债−货币资金`，口径写死防漂移）
  ③隐含 g vs 历史 base rate 判词。
- 周期/快成长/未盈利/困境反转：维持 FCF 门槛（5 年均值 >70% 且标准差 <30%）条件触发。
- MANDATORY 显式写出结果的要求两类路径各自适用。
