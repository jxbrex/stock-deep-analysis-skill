# v5.1.1 交接 — 第一变量单源加冕 + sensitivity.delta 量纲规范

> **性质：完成交接——本体已实施并验收；末章为历史 handoff 未动工内容的结转存档。**
> 立项来源：2026-09-21 影石创新报告用户实读两问（驱动卡与敏感性排序图「第一变量」
> 同屏矛盾 + 图内 1pct/20% 量纲混排），系统性调试定位后用户拍板「自动加冕 + 单位规范」。

## 根因（为什么矛盾能静默穿过门禁）

「第一变量」有两个互不相通的数据源：驱动卡角标看 LLM 手标 `drivers[].first_var`，
龙卷风图按 `sensitivity` 的 impact 降序加冕首行。v4.11.3 的一致性校验比的是 fill
**数组第 0 项**而非排序后首行——只要填报顺序 ≠ impact 排序（影石这单：毛利率写在
数组首位但 impact 小于收入增速），校验拿「毛利率 vs 毛利率」一比即过、零告警，
渲染却给收入增速加冕。且「不同名」仅软告警（stderr 打印不拒渲染），生成方不可见。
最小复现：drivers 标毛利率 + sensitivity=[毛利率 15, 收入增速 20] → 校验通过、
图加冕收入增速（修复前实测）。

量纲混排是契约缺口：`sensitivity.delta` 为自由文本，schema 只给了「±10%」示例、
无单位规范；毛利率变动写「±1pct」（百分点，本身正确）与条端/坐标轴的净利影响 %
同屏出现，读者无从分辨两种量纲。

## 决议与实施（用户拍板 2+3）

1. **第一变量单源加冕**：`charts_base._sensitivity_items`（有效行过滤 + |impact| 降序）
   与 `_first_var_name`（sensitivity 首行；缺失回退手标 first_var）为唯一定义，
   龙卷风图（charts_score）、驱动卡角标与判词前缀（charts_misc）、validate 四处同源。
   手标 `first_var` 降级为 sensitivity 缺失时的回退；与加冕不一致 → 告警（手标忽略）。
   **降序首行无同名驱动卡 → 拒渲染**（原「不同名」软告警升级；旧 fill 重渲中枪即
   当年 bug 报告，报错文案指引对齐变量名或修正 impact）。
2. **sensitivity.delta 量纲规范**：变量自身变动幅度须带单位——比例写 ±10%、百分点
   写 ±1pct（`_check_sensitivity_units`，不合规软告警）；龙卷风图注改写为
   「条长/条端/坐标轴=净利影响 %；左列=变量自身变动幅度（pct=百分点、%=比例）→
   金额影响」。

契约同步：fill-schema.md 的 `drivers`/`sensitivity` 两行（first_var 语义改写 +
不同名拒渲染 + delta 量纲）；SKILL.md Phase 0 段与产出前自查清单（v4.11.3 三卡行）。

## 结转 A：评分体系改革（原 v5.1-handoff 红队三线，2026-09-18 两轮红队评审立项）

**与本版的关联**：本版指导思想对评分的重新定位（主观横向工具、不追求精确、逻辑自洽
为硬通货）部分回应了 C1「精算浪费」的动机——时机分精算到 0.5 精度在新定位下更无必要。
整体研判时应连同指导思想一并考虑，避免两套评分哲学并存。

- **A1 短板约束**：任一 L1/L3 维度分 <4.5 → 质量分=min(质量分, 6.9)（进不了「好公司」
  行）。落点 scoring.py 后置规则 + validate 硬校验。治「明星维度+财务可疑混进重仓」。
- **A2 高分强制自我证伪**：任一维度分 ≥8 或 ≤3 时，该维 dim-block 判词末尾必含
  「反方证据：…」（≥20 字，须含可观测事实）。validate 按 scores 扫描校验。
- **A3 分数分布台账**：新增 scripts/score_dist.py 读 `_archive/_index.jsonl` 聚合
  各维分数分布，兑现「按存量报告分布校准」承诺（校准闭环从未执行）。
- **B 线 风险层去留**：建议方案=扣分并轨、披露不并轨（黄灯从独立扣分层降级为风险
  排查层：a 类并入 1E、c 类并入 1D 趋势轨、b 类压 1A 定档、d 类拆 1E/1B/3B；白盒
  清单保留为披露物；升红灯替代=命中 ≥4 项且分布 ≥3 维 → 强制红灯复核；质量分公式
  删黄灯项）。**前置依赖：A1 须同版实施**（并轨加剧稀释）。决议状态：三项全待拍板
  （含并入后维度内扣分力度是否等比放大）。
- **C1 时机分精算浪费**：三步=时机不对称化（删「≥6 上浮一档」，只做刹车）/ 信号
  瘦身（获利盘两条留一、删 52 周高点条——价格双重计价，12→8 条）/ 下调一档具体化
  为建仓方式写进 12 章。取舍：时机分退出仓位决策链（降级方案=只做不对称化）。
- **C2 分型循环论证**：成长两型合并（快速成长并入成长型，增速分层进 3A 锚）；
  权重浮动只许业务属性驱动、禁财务数值驱动；分型判据清单化（每型 3-4 个 yes/no
  可观测判据进 fill 结构化字段，validate 校验）。**排序最先动——循环污染评分地基。**
- **C3 阶梯跳变+固定权重**：锚表改分段线性插值（思考按档、计算连续）；四件套权重
  随分型浮动（周期 40/30/25/5，稳定价值 30/15/20/35，成长 45/30/25/0，未盈利
  40/30/30/0，困境反转 40/35/20/5）——成长股股息权重归零消除系统性惩罚；机制二
  「封顶后 7.7<8」算术须按各型重算。
- **三线依赖**：C2 与 B 线同动权重表须同版；C1 与 B 线同改决策链须同版；A1 是全体
  前置。建议顺序：A→C2→B→C1/C3，每步独立可回归。
- **议题 E：盈亏比（原「赔率」）命名与分母失真**（v5.1.0 实报后用户提出，已拍板
  改名、**本轮不动代码**）：
  - **名不正**：公式（基础中值−现价）÷（现价−悲观下限）= 盈利率÷亏损率，数学
    无错，但「赔率」是博彩借词——博彩赔率三要件（固定赌注/二元结果/契约化亏损
    边界）在股票语境一个都不成立，名字诱导读者按「19 倍下注机会」误读。已拍板
    改名「**盈亏比**」（reward/risk 标准译名）；改名后评分锚语义不变（≥2→8.5、
    ∞须硬地板→10 的分档对「上下路长度比」依然成立），v5.2 与下批评分改革同版落地
    （charts_scenario 卡文案/scoring.md 锚表措辞/fill-schema 行/golden 重建）。
  - **深跌失真**：分母=现价−悲观下限，是估值判断而非硬地板。锚纪律钉住悲观下限
    不许随价动 → 现价深跌后分母变薄 → 盈亏比爆炸且对价格超敏感（股价每跌 2%
    翻一倍：45 元时 9.4，43 元时 81，42.7 元时→∞），该区间数字失去决策分辨率；
    跨公司比较时薄/厚分母系统性不可比（恒瑞 18.9 vs 假设厚分母股 2，同为
    「价格贴悲观情景」状态）。且与锚纪律存在联动：锁带结构性把深跌股推进失真区间，
    有奖励深跌的倾向——本义合理（跌了该给高分），失真只在分母趋薄段。
  - **双口径追问（未决）**：图纸口径（对悲观下限，位置度量）vs 压力口径（对净现金
    地板，恒瑞 0.59，信念度量）回答不同问题，差值=收益对判断链的依赖度；但并列
    呈现会引发「估值分用哪口径算」的评分级追问（名义 18.9→8.5 分 vs 压力 0.59→3.5
    分，差 1.25 总分）。候选修法各有利弊：分母改 min(悲观下限,硬参考)/薄分母对数化
    或封顶/双口径进评分取 min——**动评分公式，必须思虑周全**，与 C3 阶梯跳变、
    估值锚纪律联动，走 v5.2 整体研判。本期（用户拍板）只呈现层可选加「分母趋薄
    警示」也一并押后。
