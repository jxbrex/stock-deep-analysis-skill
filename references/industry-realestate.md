# 地产行业附录（开发型地产）

> 开发型地产的结算利润是 2-3 年前的销售——当期 PE 给的是旧世界的估值，周期顶部 PE 最低
> 恰是最危险的时刻。地产是融资驱动的商业模式：资产负债表右边（债务期限与成本）比利润表
> 更先决定生死，表外（少数股东/明股实债/担保）比表内更重要。**本附录用于替换通用口径**：
> 1D 盈利质量红旗清单、1D 财务体检表、估值方法、Phase 0 关键驱动识别。
> **触发**：房地产开发为主业（开发销售收入占营收 >50%，A 股/港股内房）时，本附录优先级
> 高于 `scoring.md` 的通用口径。
> **分型与权重**：默认「周期股」分型（利润随销售/结算周期波动）；已发生债务违约/重组的
> 按「困境反转」（豁免规则照 SKILL.md Phase 0.5——财务恶化是前提而非否决项，但造假/立案/
> 退市风险不豁免）。L1 层内权重复用对应分型行（`scoring.md` 矩阵），不新增行业权重。
> **边界**：商业地产/REIT/物业服务（收租型）不适用 NAV 主锚，走通用稳定价值/DCF 口径。

## 通用原则（三条，先读）

1. **销售是先行指标，结算是滞后指标**。今天的合同销售 = 两年后的营收；分析必须站在
   销售口径上，利润表只用于验证毛利与减值。
2. **现金流 > 净资产 > 利润**。三道红线时代的生死线是债务到期墙与再融资成本，
   不是账面盈利。幸存者与出险者是两个物种，不要用同一把折让率尺子。
3. **少数股东是利润转移与隐性杠杆的黑洞**。权益占比与损益占比的背离程度，
   是地产财报可信度的第一检查项。

## 一、1D 红旗清单替换（四项，替代现金含量/应收/存货/毛利率；审计意见属红灯 a 项）

| 红旗项 | 口径 | 判定 |
|--------|------|------|
| 短债覆盖 | 非受限货币资金 ÷ 短期有息负债 | <1 且连续两期恶化 → 红旗 |
| 明股实债迹象 | 少数股东权益占比 vs 少数股东损益占比 | 权益占比 ≫ 损益占比（如 40% vs 10%）→ 红旗 |
| 合同负债趋势 | 合同负债 ÷ 营业收入 | 连续 2 年下行（销售蓄水池枯竭）→ 红旗 |
| 利息资本化率 | 资本化利息 ÷ 总利息支出 | >90% 且显著高于同业（费用后移美化利润）→ 红旗 |

## 二、1D 体检表（替代 ROE 趋势/毛利率/负债率/FCF）

| 指标 | 关注点 |
|------|--------|
| 合同销售额与增速 | 月度口径，与百强/行业增速对照；量是 NAV 的第一输入 |
| 回款率 | 销售回款 ÷ 合同销售；<90% 警惕渠道压货/工抵房 |
| 土储质量 | 总建面、一二线城市占比、去化周期；三四线重仓 → NAV 折让加深 |
| 净负债率与融资成本 | 净负债率趋势 + 加权平均融资成本 vs 央国企基准 |
| 已售未结毛利率 | 未来 2 年结算利润已被锁定，看它不看当期毛利 |
| 经营性现金流 | 买地强度 vs 销售回款的匹配（逆势加仓 = 赌政策） |

## 三、估值方法

**NAV 重估净资产（主锚）**：

```
NAV = 土储与在建重估价值 + 持有物业公允价值 + 其他净资产 − 有息净负债 − 少数股东权益
每股 NAV = NAV ÷ 股本；目标价 = 每股 NAV ×（1 − 折让率）
```

- **土储重估**：可售货值 × 稳态净利率（参考公司已售未结毛利率，不用峰值毛利）折现；
  或简化按 成本 ×（1 + 合理增值率）。假设必须写明。
- **折让率（必须历史校准，给区间不给点）**：港股内房常态 50-70%（出险房企 80%+）、
  A 股开发 30-50%；流动性、治理、土储质量、信用状态决定带内位置。
- **交叉验证**：PB-band 历史分位、清算价值对照（极端下行情景）、幸存央国企辅以
  税后股息率（分红可持续性验证）。
- **禁用**：当期 PE（结算滞后 2-3 年，顶底反向）、PEG（g 为负时无意义）。

**fill 折算规则（mcap 市值口径，脚本原生支持）**：

- 三情景由合同销售路径与折让率假设定义（悲观 = 销售继续下行+折让走阔；基础 = 销售企稳；
  乐观 = 政策放松+折让收敛），每情景算目标总市值 → `"mcap":[低,高]`（亿元）；
  **不用 profit+pe 口径**（结算利润失真）。
- `valuation_inputs`：`pe_ttm` 填 现市值 ÷ NAV 总值，`pe_band` 填合理 P/NAV 带
  （= 1 − 折让率区间，如折让 50-70% → [0.3, 0.5]），`metric_label` 填 `"P/NAV"`。
- **NAV 分项表**（土储/持有物业/净负债/少数股东各项与合计，含 .source 标注）与折让率
  历史依据必须完整写在 `valuation_html` 正文——只填 mcap 不写推导 = 违反反幻觉纪律。

## 四、Phase 0 关键驱动

**合同销售增速**（量，第一变量——估"销售 ±10% → NAV 与现金流 ±Y%"）>
债务到期墙与再融资成本（未来 12 个月到期规模 vs 可用现金与融资渠道）>
政策（限购放松/按揭利率/保交楼）。三情景围绕销售路径与折让率构建。

## 五、财报可信度替代项（M-Score 部分适用：预售制应计项结构失真）

人工判断替代核查项，评级接入规则与 `forensic-accounting.md` 第 7 节一致
（C → 黄灯 d 类至少扣 0.5；D → 红灯回避）：

- 少数股东权益 vs 损益占比背离（明股实债/利润转移的第一信号）；
- 利息资本化率与同业对比（费用后移程度）；
- 投资物业公允价值重估收益占利润比（>20% 且依赖评估假设上调 → 虚增利润）；
- 存货跌价计提充分性（计提比例 vs 同城市房价跌幅，计提不足 = 利润前置）。

审计意见仍是必查红灯项（供红灯 a 项判定，不再列于 1D 红旗清单）。

## 数据来源提示

- 合同销售：公司月度公告 + 克而瑞/中指院第三方排行交叉验证（定性搜索）。
- 土储/已售未结/融资成本：年报经营讨论章节（定性搜索 + 年报查证）。
- 短债覆盖/少数股东/利息资本化：em_fetch E3 资产负债表 + 现金流量表字段手工算。
- 三道红线口径：年报披露 + 定性搜索；出险房企债务重组进展以公告为准。
- 港股内房财务：妙想 `mx_hk_finance_data` 首选，字段名与 A 股不同。
