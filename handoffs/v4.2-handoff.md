## 本轮做了什么（v4.1 → v4.2）

### 取数与脚本
- **em_fetch.py 新增**：无风险利率（东财中债 10Y，列编码 EMM00166466）；TTM 税前股息率
  （tushare dividend 实施口径，近 12 月每股派息 ÷ 现价）；资本开支行（现金流量表
  「购建固定资产、无形资产和其他长期资产支付的现金」，DCF capex 直接取此口径）。
- **新增 extract_review.py**：旧报告 HTML → prev 锚点/三情景假设/仪表盘与复盘表格的结构化 JSON
  （回测模式机械提取，替代模型读旧 HTML 自由发挥）。文件不存在时给中文提示（附件先落盘）。

  正文出现 L1/L3/L4/1D 代号告警（报告引用只准章节编号）。
- **表格对齐引擎重写为内容投票**：裸 td 按内容判数值/文字、纯文字格误标 num 自动纠正
  （恒瑞核心业务行、中免财务健康表两类实证修复）。

### 评分体系（经 18 份报告回测校准）

  3C 写不出月份最高 5.9。
- **1D 改为趋势+流动性双轨**（方案 C）：1D 评趋势方向+流动性风险，回报水平归 1F，
  消除中芯式双重扣分；短债覆盖 <1 但 OCF/短债 >2 豁免上调一档；负债一律有息负债率口径。

## 思考题

### 1. 接下来 skill 的优化方向（按优先级）

① **评分体系统计校准**（v4.1 交接遗留，仍是最有价值的一件）：用复盘档案检验
"分数 vs 未来收益"的关系——攒够 10+ 份复盘后，统计质量分/估值分各档位的实际收益分布，
验证决策矩阵的档位门槛是否合理。这是从"自洽"走向"有效"的唯一路径。
② **弱模型（deepseek）全流程回归**（v4.1 遗留）：新锚全部是清单/分档制，理论上对弱模型
友好，但需要实测验证——特别是 3A 三条细则和 1D 双轨这两个"带判断的锚"。
③ **旧版单轨报告兼容**：extract_review 对 v4.0 前报告（综合分单轨）prev 三轨提取为 null，
目前靠模型兜底；存量旧报告越来越少，优先级低，若再遇到就加"综合分→quality 映射+告警"。
④ **腾讯式薄报告的内容地板加固**：腾讯 08-14 版 1A/3B/3C 只有一句话也过了地板——
dim-block 数量校验挡不住"每块一句话"，极端分告警（本轮新增）只覆盖 ≥8/≤3；
可考虑 dim-block 纯文本 <80 字即告警（不管什么分）。
⑤ **评分漂移监控**：同一公司短期内两份报告（中芯 6.16 vs 6.29 同日两版，离散度 38% vs 90%）
暴露三情景宽度本身是噪声源——可在复盘模式下加"关键假设变更表"硬校验，强制解释
相邻两版假设差异。

### 2. 本轮工作总结（交接要点）

本轮从 v4.1 出发做了三件事：**（a）补齐评分体系的最后一块短板**——九个质量维度 +
时机分全部从"软约束"升级为"分档锚/清单锚"，并用 18 份存量报告做了系统回测验证
（子智能体只提取结构化原文、重打分由主模型按锚执行，这本身就是委派纪律的一次实战）；
**（b）修掉一批工程摩擦**——fill JSON 分段写盘（治 504 卡死）、渲染器 UTF-8、【】误伤、
单位叠加、表格对齐内容投票、Hero 留白结构修复、港股 tushare MCP 限流规则；
**（c）把几条关键设计哲学写死在文档里防止回退**——9.5+ 治理不设路径、离散度只在极端档调节、

### 总览

审计发现 18 条，分三组：

- **A 组 · 复杂度/过度工程**：`render_report.py` 堆了一整层「模型写错，脚本自动修」的防御性代码
  （表格自动对齐引擎 + 场景转置 + 类名归一 + 转义修复 + 旧键名兼容），合计约 300 行，是本项目
  复杂度失控的根因。
- **B 组 · 运行效率**：`em_fetch.py` 单次 A 股运行对同一 tushare 接口重复调用（`daily_basic`×3、
  `income`×3、`fina_indicator`×2~3、`cashflow`×2、`balancesheet`×2），tushare 会员有分钟/日级限流，
  既慢又烧额度；另有若干小处可优化。
- **C 组 · 结构/文档冗余**：决策矩阵/仓位档位/四件套公式/权重在四处重复描述；`summarize`、
  `validate_content`、`render` 三个巨函数；若干 hack 写法。

**net 估算**：全做可减 `render_report.py` 约 300~350 行、`em_fetch.py` 约 80~120 行，**无新增依赖**，
全部用标准库 + 既有代码收敛。
