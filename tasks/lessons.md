# 仓库教训录

## 2026-09-13 报告产物核查：先对齐用户所指的「图/功能」是哪个，再下结论

海油报告六问复核时，用户问「机构预期图去哪了」，我把「机构预期图」直接等同于
growth_plot 利润增长图（v4.9），验证 SVG 在位后断言「非缺陷，图已渲染」。用户贴出
上轮示意图后才发现：用户指的是**逐机构散点分布图**（卖方分布 vs 本文假设），该图
只做到 `artifacts/_gap_*_demo.html`（v3 预览）阶段，从未落进 skill 代码。

规则：

1. **用户指认报告缺某物时，先让用户（或示意图）锁定具体所指**，再查产物；
   不要拿仓库里「名字最像」的既有功能去套。
2. **demo ≠ 实现**：artifacts/ 下的效果预览（尤其当日新建的 `_demo.html`）必须检查
   是否有对应的 scripts/ 构建函数 + fill-schema 字段 + handoff 记录，三者缺一即为
   「设计了没落地」，报告里没有是正常结果。
3. 「验证过 SVG 存在」只能证明**某张**图渲染了，不能证明**用户要的那张**图渲染了。
