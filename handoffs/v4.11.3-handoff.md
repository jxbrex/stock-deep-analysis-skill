## 一、三卡字段化（模型填数据、脚本拼 HTML，沿用 tornado/triggers 先例）

- **P0 驱动卡**（`drivers`/`driver_verdict` → 模板 `{{DRIVER_CARDS_HTML}}`，s2 龙卷风前）：
  1-2 个关键驱动各一卡（弹性大数字 + 当前值/撕扯力量备注 + 悲观/基础/乐观三情景锚
  标签），卡下判词横条（「为什么 X 是第一变量：」前缀脚本按 first_var 名自动拼）。
  p0_html 手写「为什么…」info-card 写法废止（检出告警）；info-card 内容全部融卡
  （三重力量进备注、三情景进锚标签、判词进横条），信息零损失。
- **周期阶段卡**（`cycle_stages` → `{{CYCLE_STAGES_HTML}}`，s10 两图后 cycle_html 前）：
  手写阶段拆解表 → 3-6 张步骤卡网格，大序号 + 加粗日期行承载顺序、恰 1 个 current
  「本轮」高亮。**网格去箭头**：03→04 跨行 ↓ 箭头会误指 06（demo 实证）；蛇形布局
  被否（第二行右往左读违背 Z 字习惯）。cycle_html 手写阶段表写法废止（检出告警）。
- **DCF 双卡**（`dcf` → `{{DCF_CARDS_HTML}}`，s7 valuation_html 与估值分计算卡之间）：
  保守 DCF 每股值 / 现价隐含永续增速两卡（参数与反推口径进 sub）+ 判词；
  **与现价比价脚本算**（value÷fill.price−1，防伪链同源现价），模型不手算。
  稳健成长/稳定价值缺失强制告警；valuation_html 手写 DCF 表写法废止。
- 三字段全部**软告警迁移**：缺失或旧手写形态不拒渲染，archive 旧 fill 重渲只多告警；
  旧形态不自动删（正则删手写 HTML 太脆，_clean_peers_matrix 已是风险先例）。

## 四、槽位契约（fill-schema 新节）

卡片/短文本槽位上限一览表（concl ≤12 字既定 / drv-name ≤12 / drv-note 显示宽 ≤300
≈3 行 / stage-driver 显示宽 ≤48 / scenario.trigger ≤15 既定 / 徽章一词等）。
**宽度口径：CJK 计 2、ASCII 计 1**（纯字符数对中英混排过紧：「PE 25x→17.2x」26 字符
实测单行可读；宁德融合版备注 137 字 ≈3 行可读，原 ≤24/≤90 双双过紧已改宽度制）。
校验唯一权威在 validate.py（v4.11.2 制度），契约表只供写作前自查，不镜像报错。
