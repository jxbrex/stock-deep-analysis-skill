## 审查发现总账（按优先级）

### P0（产出错误结论）

- **决策矩阵质量分 <4 落位 bug**：`_matrix_slot` 末行返回字符串 `"不建议参与"` 而非档位 `0`，
  `build_position_card` 的 `isinstance(pos, int)` / `pos == 0` 均接不住 → 落入观察池分支。
  烂公司得到「观察池」徽章，且同一张卡里落位文字与徽章自相矛盾。

### P1（契约违背 / 计算错误 / 文档漂移）

- 三情景按排序后位置取 `rows[0]/[1]/[-1]`，多余 key 会错位取错情景；
- 年化中枢只用 valuation 级 horizon，忽略情景级（2 年情景按 12 个月年化，收益高估近一倍）；
- `--check` 不跑 `compute_valuation_score`——退出码 0 ≠ 可渲染；
- 质量分汇总 footer 等式不成立（红旗在层分里扣过一次，footer 又列一次）；
- em_fetch 无 429 检测，限流时原样重试 + 静默吞错（与文档「硬停」规则相反）；
- `secid_of` 与 `to_ts_code` 市场映射口径不一致（北交所/B 股取错票，静默无告警）；
  顺带发现既有 bug：`to_ts_code` 把北交所 92 开头误判为沪市；
- 契约标「必填」的 timing_scores/yellow_deductions/thesis_html 实际只告警（缺黄灯键 = 质量分虚高）；
- 模板与 em_fetch 港股摘要币种硬编码「元/¥」（港股报告事实性错误）；
- 离散度阈值文档漂移实锤：scoring.md 与代码已收紧为 40/90，valuation.md 还是旧的 30/60。

### P2（边界与健壮性，节选）

闰日崩溃（div_yield 取数）；同比负分母算出误导性增长率；净利润为负时现金含量红旗误判；
M-Score 毛利率 ≤0 失真；timing 缺维静默按 0；负扣分可绕过黄灯上限；PE 倒挂不校验；
thesis 一致性校验在脚本中枢价 ≤0 时失效；fill JSON 无 BOM 容错；输出静默覆盖；
Hero 估值着色 ≥7 vs 徽章 ≥8 不一致；dim-block 计数两口径；小写 {{}} 残留不检出；
RENDERER_VERSION 滞后；死代码若干；extract_review 正则裸 `.group()` 崩溃（写测试时实测抓到）。

### 结构层

- 「唯一权威」原则被自己的复述击穿（数值规则写在 4+ 处，已出现漂移实例）；
- frontmatter description ~600 字符含权重数字（每次技能列表注入全场付费）；
- 硬门禁 6+4 与「省 token」设计目标矛盾；
- 事故注释堆积（SKILL.md 8 处「XX 实证」）；回测触发靠肉眼扫目录 + extract_review 正则脆弱；
- 测试覆盖与 3300 行脚本严重不匹配（仅 1 个 mcap 冒烟）。

   首先排查此处（可能需 `81.`）。
