# stock-deep-analysis — 个股深度分析技能（V4.3）

基于「质量 × 估值 × 时机」三轨评分框架的个股深度分析技能（Kimi Code / ZCode 通用），
一键取数、脚本拼装，生成单文件 HTML 研究报告。

> ⚠️ 本技能产出的报告为 AI 生成的研究笔记，不构成投资建议。

## V4.3 核心变化

- **防绕行**：渲染输出嵌入 `generated by render_report.py` 版本标记（render 报错后手写
  全文 HTML 绕行可 grep 检出）；缺 `.source` 的报错文案附修复指引。
- **内容地板加厚**：thesis 只有目标价 → 告警；dim-block 纯文本 <40 字拒渲染、<80 字告警
  （治弱模型「每块一句话」缩水）。
- **`--check` 预检模式**：fill 落盘后自检的唯一合法方式（解析+评分+地板全预检，退出码 0/2），
  取代手写 `python -c` 内联自检。
- **取数提速**：ts_call 透明缓存 + 财务三表统一窗口，实测每股少 8 次 tushare 请求
  （income/cashflow/balancesheet/fina_indicator 各 1 次）。
- **子智能体条件强制**：peer ≥3 批量取数 / 公告 PDF 下载必须委派（SKILL 与 data-collection
  口径统一，此前两文矛盾致委派时有时无），其余不委派。
- **回测模式加「关键假设变更表」硬要求**（防相邻两版评分漂移）。
- 模板：Hero 双分卡等宽等高、时机判定小表合计行加粗、结尾不再双横线。
- 瘦身：删旧方向三情景表转置 / 幻觉类名归一 / 时机层旧键名兼容（改显式报错）；
  估值四件套映射合并为阈值表；SVG 坐标/刻度抽共享 helper。

## V4.2 核心变化

- **全维度评分锚定**：九个质量维度（1A-1F + 3A-3C）+ 时机分（筹码面/技术面）全部从
  软约束升级为分档锚/清单锚（经 18 份存量报告回测校准）——模型只做"信号命中了吗"
  的判断题，不再凭感觉打分。
- **1D 财务健康改趋势+流动性双轨**：1D 评趋势方向与流动性风险，回报水平归 1F，
  消除同一指标双重扣分；短债覆盖 <1 但经营现金流/短债 >2 豁免上调一档。
- **1E 治理天花板升至 9.0**：正向锚三条互不重叠（分红纪律/回购注销/十年期卓越记录），
  清单封顶 +2.0；9.5+ 不设路径（治理是卫生因素，尾部风险不可见）。
- **离散度调节收紧到极端档**：>90% 降档 / <40% 上浮（旧阈值触发率 70% 形同普遍降档）。
- **取数自动化**：em_fetch 新增中债 10Y 无风险利率、TTM 股息率（tushare 实施口径）、
  资本开支（DCF 直接可用）；新增 `extract_review.py`（旧报告复盘锚点机械提取）。
- **fill JSON 分段写盘硬规则**：超 ~8k token 分 2-3 段（Write+append），防单次超长响应
  撞网关超时；渲染器 UTF-8 输出、表格对齐内容投票、极端分证据告警等多项加固。
- **子智能体默认委派**：peer 批量取数与新闻初筛默认下放（回传只准结构化原文数据），
  分型/评分/三情景/判词绝不下放。

## V4.1 核心变化

- **估值分脚本强制计算**：无手填路径——模型只填 `valuation_inputs` 四件套
  （pe_ttm/pe_band/div_yield/risk_free）+ `valuation` 结构化三情景，脚本按
  中枢40/赔率25/合理倍数25/股息10 算分并覆盖任何手填值。
- **内容地板硬校验**：conclusion ≥200 字、L1 六维/L3 三维 dim-block 数量、同业含表格、
  每表配 .source、thesis 三价与脚本计算一致等，不达标渲染器直接拒渲染。
- **评分汇总章恢复**（新第 6 章，脚本生成）+ 11 章顶三轨汇总卡（判词/矩阵落位/调节轨迹/最终仓位，脚本生成）。
- **决策矩阵阈值统一**：「好价格」门槛升至估值分 ≥8；估值判词四档 ≥8 深度安全边际 /
  6-7.9 合理偏便宜 / 4-5.9 合理无安全边际 / <4 贵；调节规则固定优先级，档位序列 0/5/10/20，
  上浮一档 20% 硬顶。
- **1D 红旗扣分结构化**：改走 `red_deductions` 字段（每项扣 1 分，脚本从 1D 扣、下限 0），
  不再手并入 scores。

## V4.0 核心变化

- **估值独立成轨**：质量分只答"值不值得长期拥有"（L1 六维 + L3 三维，不含估值）；
  估值分独立成价格轨，答"现在贵不贵"；时机分只做 ±1 档微调。决策主轴 = 质量分 × 估值分，
  「好公司太贵」的正确结论是「等」，而不是扣质量分。
- **主文件瘦身 + 参考文件分层**：SKILL.md 只留工作流骨架与硬规则，评分/估值/取数/
  财报核查/回测细则下沉到 `references/*.md`（按需加载，省上下文）。
- **数据通道升级**：tushare 优先 + 东方财富公开接口兜底，新增 PE/PB 历史分位、业绩预告/
  快报、治理包（质押/增减持/回购）、券商一致预期、审计意见、财报披露计划日；
  妙想 MCP 直调层（港股财务 / 定性检索 / 大宗商品 / 筹码分布）。

## 功能

- **三轨评分**：质量分（L1 六维 + L3 三维，不含估值）+ 估值分（独立价格轨）+ 时机分
  （筹码面 67% + 技术面 33%，微调）；红/黄灯层不占权重（红灯熔断 + 黄灯扣分）
- **股票分型**：周期股 / 稳定价值金融 / 稳健成长 / 快速成长 / 未盈利管线 / 困境反转，
  分型自动调整层权重与估值方法
- **三情景估值**：悲观/基础/乐观（由关键利润驱动定义）+ 历史时段匹配 PE 校准 +
  年化中枢收益/赔率/离散度三指标；报告内自动生成目标价走廊图（脚本算，模型不手算坐标）
- **回测模式**：同股再分析自动启用——「复盘更新」对比条（分数差值脚本算）、文件名自动加
  「复盘」、R 回测复盘章节（复盘四格表 + 新财报 vs 原假设）、变更高亮 `.rev`
- **同业对比**：当前指标表 + 3 年趋势表（文字方向标注）+ 估值-质量散点图
  （ROE×PE 直角坐标系精确点位，脚本按 `peers_plot` 生成 SVG）
- **预期差拆解**：与卖方一致预期的分歧逐项对照（A/B/C 三档降级）
- **盈利质量红旗**：现金含量/应收/存货/毛利率异常/审计意见五项检查（三态标注，禁伪装通过）
- **财报可信度评级**：应计比率 + Beneish M-Score + 审计意见（`forensic-accounting.md`）
- **治理混合制评分**：质押/减持/年龄/处罚量化清单 + ±1 判断调整
- **跟踪仪表盘**：关键指标 + 触发条件 + 下次审查；回测模式首段为旧触发条件核对表
- **数据获取**：tushare 优先、东方财富公开 API 自动兜底（em_fetch.py 内置）；
  tushare token 自动发现（`TUSHARE_TOKEN` 环境变量 > ZCode config 的 `mcp.servers.tushare.url`），
  无需手工传入；A 股 + 港股（5 位代码自动识别）
- **妙想 MCP 直调层**（可选，东财官方免费 AI 数据服务）：港股财务首选、定性检索主力、
  大宗商品价格、筹码分布

## 报告生成流程（fill→render）

1. 调研取数：`python em_fetch.py [代码] --peers=...`（完整输出直接进上下文，禁止 `| tail` 截断）；
   peers 批量取数与新闻初筛默认委派子智能体（回传结构化原文数据），定性调研禁止委派
2. 三轨评分 + 三情景估值（分析在主会话完成；九维度+时机分全部分档锚/清单锚定）
3. 写 fill-data JSON（契约见 `references/fill-schema.md`；Write 直接写盘，超 ~8k token 分 2-3 段）
4. 渲染：`python render_report.py _fill_[代码].json`
   ——三轨评分、徽章色、图形 SVG、对齐修正、文件名（`公司名-代码-质量分-估值分-日期.html`）
   全部脚本计算，零拼装 token

## 安装

将 `stock-deep-analysis/` 目录放入技能目录：

- 用户级：`~/.agents/skills/` 或 `~/.zcode/skills/`
- 项目级：`<project>/.agents/skills/` 或 `<project>/.zcode/skills/`

依赖：Python 3.8+、curl（Windows 10+ 自带）；tushare token 可选（无 token 自动走东财公开接口）。
