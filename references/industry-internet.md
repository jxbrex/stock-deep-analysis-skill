# 互联网行业附录（多元平台型）

> 平台互联网的整体利润是一个"混合物"——成熟现金牛与烧钱新业务混在一个数字里，
> 整体 PE 掩盖结构；而"经调整利润"是管理层口径，SBC 与减值调节幅度必须先审后用。
> **本附录用于替换通用口径**：1D 盈利质量红旗清单、1D 财务体检表、估值方法、
> Phase 0 关键驱动识别。
> **触发**：≥2 个独立可估值业务板块的平台型互联网公司（腾讯/阿里/美团/京东类，
> 港股/中概为主）时，本附录优先级高于 `scoring.md` 的通用口径。
> **分型与权重**：按增速落位「快速成长」（>25%）或「稳健成长」（10-25%），
> L1 层内权重复用对应分型行（`scoring.md` 矩阵），不新增行业权重。
> **边界**：单一业务互联网公司（纯游戏/纯工具/纯电商 SaaS）不适用 SOTP，走通用口径。

## 通用原则（三条，先读）

1. **分部拆开才知道钱从哪来**。整体 PE 合理可能只是因为核心业务被低估、亏损业务被
   免费赠送——也可能相反。SOTP 的意义是强迫逐块定价。
2. **"经调整利润"不是免费午餐**。SBC（股权激励）是真实成本：用经调整利润估值时，
   必须同时披露 SBC 占经调整利润比；占比 >20% 且持续上行 → 1D 扣分锚。
3. **投资组合是隐性资产也是减值风险**。上市/非上市投资按公允价值重估后计入 SOTP，
   并打持有折价——账面长期不随市场调整的，先查减值是否滞后。

## 一、1D 红旗清单替换（保留通用"利润现金含量"，替换应收/存货/毛利率三项——平台口径不适用）

| 红旗项 | 口径 | 判定 |
|--------|------|------|
| 利润现金含量 | 经营现金流净额 ÷ 净利润 | 连续 2 年 <0.7 → 红旗（通用项保留） |
| 经调整利润背离 | （经调整净利 − 报表净利）÷ 报表净利 | 连续扩大且 >50%（SBC/减值过度调节）→ 红旗 |
| 投资资产减值滞后 | 投资组合账面价值 vs 可比市场公允变动 | 市场大跌而账面不减值/减值显著不足 → 红旗 |
| 商誉占比 | 商誉 ÷ 净资产 | >30% 且并购标的业绩变脸 → 红旗 |

## 二、1D 体检表（替代通用 ROE/毛利率/负债率/FCF 的解读侧重）

| 指标 | 关注点 |
|------|--------|
| 分部收入与分部利润率 | 各板块收入增速 + 利润率趋势（结构变化比整体增速重要） |
| 核心变现指标 | 广告加载率/eCPM、游戏流水、GMV 货币化率、外卖 UE——按主业选取 |
| 用户指标 | MAU/DAU/时长/留存趋势；用户见顶而变现率提升 → 增长质量切换 |
| SBC 占比 | SBC ÷ 经调整利润；>20% 且上行 → 经调整口径失真 |
| FCF 与资本开支 | AI/云资本开支对 FCF 的吞噬节奏（算"资本开支 ÷ 经营现金流"） |
| 净现金与投资组合 | 净现金规模、投资组合公允价值（上市部分按市价重估） |
| 回购力度 | 年回购金额 ÷ 市值；回购是平台股估值底的重要支撑 |

## 三、估值方法

**SOTP 分部加总（主锚）**：

```
SOTP 市值 = Σ 分部价值（成熟业务 正常化净利×合理 PE 或 EV/EBITDA；
            新业务 PS 或可比市值；云/金融等用独立对标）
          + 净现金 + 投资组合公允价值 ×（1 − 持有折价 10-30%）
```

- **分部倍数**：各块用各自可比公司口径（广告对标广告、游戏对标游戏），倍数差异必须给理由；
  禁止全公司一刀切 PE。
- **持有折价**：投资组合 10-30%（流动性/控制权/税）；净现金不打折。
- **交叉验证**：整体经调整 PE 历史时段匹配（用前先看 SBC 占比）、FCF 收益率。
- **禁用**：单一报表 PE（混合失真）、PEG（分部增速差异大，整体 g 无意义）。

**fill 折算规则（两口径二选一）**：

- **首选利润口径**：平台股有真实利润——profit 填经调整归母净利（口径在 `valuation_html`
  声明，SBC 占比必须同时披露），pe 区间填 SOTP 隐含整体倍数（= 各情景 SOTP 市值 ÷ 经调整净利）；
  `pe_ttm` 填经调整 PE(TTM)，`pe_band` 填 SOTP 合理倍数带，`metric_label` 填 `"经调整PE"`。
- **备选 mcap 口径**：分部含未盈利重资产业务、整体利润严重失真时，每情景直接给 SOTP
  市值区间 `"mcap":[低,高]`（亿元），`metric_label` 填 `"P/SOTP"`。
- 无论哪口径，**SOTP 分部加总表**（每分部：估值口径/倍数/分部价值，含 .source 标注）
  必须完整写在 `valuation_html` 正文。

## 四、Phase 0 关键驱动

**核心业务变现斜率**（广告/游戏/电商，第一变量——估"变现率 ±X% → 分部利润 ±Y%"）>
监管政策（反垄断/内容/金融监管节奏）> 新业务减亏节奏与 AI 资本开支回报。
三情景围绕核心变现路径构建，而非拍整体利润区间。

## 五、财报可信度（M-Score 基本适用，另加行业专项）

M-Score 照 `forensic-accounting.md` 通用流程执行，另加以下人工核查项，
评级接入规则同第 7 节（C → 黄灯 d 类至少扣 0.5；D → 红灯回避）：

- SBC 调节幅度趋势（经调整 vs 报表裂口持续扩大 = 利润质量下降）；
- 投资损益与减值确认口径（并表/权益法/FVOCI 之间的选择性安排）；
- 商誉减值测试假设充分性（并购标的现金流假设 vs 实际）；
- VIE 结构定性提示（中概/港股协议控制与监管风险，不评分但必须在 L4 陈述）。

审计意见仍是必查红灯项（供 L4 红灯 a 判定，不再列于 1D 红旗清单）。

## 数据来源提示

- 分部数据：年报/季报分部附注；港股走妙想 `mx_hk_finance_data` 首选。
- 经调整利润口径：公司业绩公告 Non-IFRS 调节表（SBC/减值/投资损益逐项）。
- 用户/流水指标：季报运营数据、业绩会纪要（定性搜索）。
- 投资组合：年报披露 + 上市持仓按市价重估（em_fetch 无字段，手工 + 定性搜索）。
- 回购：公司公告/翌日披露报表（港股）累计。
