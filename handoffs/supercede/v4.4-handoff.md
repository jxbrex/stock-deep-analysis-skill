### 日志暴露的问题与处置（N1-N5）

- **N1 单引号属性陷阱（本轮修复）**：fill JSON 内嵌 HTML 写 `class='source'`（JSON 字符串
  双引号 → 内嵌 HTML 天然诱导单引号避转义），渲染器 source/rev 计数只认双引号 → 误报拒渲染。
  修复：`_load_fill` 入库时 `_norm_class_quote` 递归归一 `class='x'`→`class="x"`
  （正则 `[^'"]*` 防混合引号跨段误吞）。fill-schema 补说明。验证：单引号变体 fill 渲染输出
  与双引号版逐字节一致。
- **N2 target_range 语义（文档修复）**：模型填三情景全区间被脚本按基础情景区间覆盖告警，
  花 ~6 步读脚本源码才懂口径。fill-schema 已写明「基础情景区间，脚本自算覆盖」。
- **N3 heredoc 违规（文档再点名）**：`cat >> << 'EOF'` 追加分段侥幸未炸。SKILL 禁止条补实证。
  无事后检测手段，不加机制。
- **N4「不 Read 脚本」细化（文档修复）**：模型为诊断 N1/N2 读 render 源码属合理调试。
  规则改为「禁读脚本学结构，允许 grep/局部读诊断报错」。
- **N5 定性研究缺席（观察项）**：全程零新闻/公告检索，卖方观点只靠 em_fetch 一致预期。
  不违规但单薄——与「MCP 检索类可委派」联动观察下一份报告。
