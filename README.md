# stock-deep-analysis — 个股深度分析技能

基于「质量 × 估值 × 时机」三轨评分框架的个股深度分析技能（Kimi Code / ZCode 通用）。
一键取数、脚本拼装，产出单文件自包含 HTML 研究报告。

> ⚠️ 本技能产出的报告为 AI 生成的研究笔记，不构成投资建议。

## 整体逻辑

### 指导思想（第一性）

本技能的第一性是**价值投资**：市场先生负责报价，不负责定价——内在价值锚独立于
即时价格；安全边际=价值−价格，价值随价动则安全边际恒失效。由此定三轨分工：
**评分**是主观的横向对比工具（分数值不追求客观精确，硬通货是逻辑自洽与信息完整）；
**估值**是交易决策的决定性变量（不承诺数字准确，承诺假设可追溯、口径一致、
锚不滑动，以范围表达并靠回测持续精进）。

### 三轨评分：不是一个混合分，而是三个各司其职的分

| 轨 | 回答什么 | 决策作用 |
|----|---------|---------|
| **质量分** | 这家公司值不值得长期拥有 | 能不能买（资格） |
| **估值分** | 现在这个价格贵不贵 | 买多少 / 等不等 |
| **时机分** | 市场情绪与筹码状态 | ±1 档微调，不跨「买/不买」门槛 |

决策主轴 = 质量分 × 估值分。「好公司太贵」的正确结论是「等」，不是扣质量分——
估值分永远不进质量分。风险层（红/黄灯）不占权重：红灯直接熔断，黄灯从质量分往下扣。

### 分型定尺子

不用一套尺子量所有股票。六型分类（周期 / 稳定价值金融 / 成长型 / 成熟停滞 /
未盈利管线 / 困境反转）决定层权重与估值方法——成长型按历史扣非 CAGR 再分高速层
（>25%）与中速层（5-25%）。v5.3.0 起判据不再是特征描述，而是**该型估值方法成立的
前提条件**（答案结构化落 `typing_evidence`，撞车只有 {周期股, 成长型} 一对可共存）。
金融、创新药、开发型地产、平台互联网另有行业附录（红旗清单、体检表、估值主锚全套替换）。

## 方法论：成熟框架如何落地

本体系不是凭空发明的——它站在一批经过实证检验的成熟框架上，但**只借机制、不抄表单**：
每个框架落地前都回答三个问题——它回答什么问题？放进哪一维？判据怎么写成可观测、
可校验的形式？下面是完整映射地图（逐条取舍结论的权威存档在 `references/scoring.md`
附录「成熟质量框架映射与取舍」，备查防重复调研）。

### 质量分的骨架：九维两层

质量分 = L1 公司本质六维 + L3 未来预期三维 − 黄灯扣分，层占比与维度权重按分型浮动：

| 层 | 维度 | 回答什么 | 借来的成熟机制 |
|----|------|---------|---------------|
| L1 | 4.1 赛道与宏观 | 这个行业赚不赚钱 | **产业生命周期/S 曲线**（渗透率坐标两步法）+ **波特五力之替代品威胁**必答句 |
| L1 | 4.2 产业链位置 | 在链条里有没有议价权 | **波特五力之供应商/买方议价能力**（「有份额≠有定价权」） |
| L1 | 4.3 商业模式与护城河 | 凭什么守住利润 | **晨星经济护城河五源 + 7 Powers 逆定位** + 三硬约束（下详） |
| L1 | 4.4 财务健康 | 利润是不是真钱、有没有流动性风险 | **盈利质量红旗四项清单**（现金含量/应收/存货/毛利率异常）+ **Beneish M-Score** 财报可信度评级 |
| L1 | 4.5 治理与资本配置 | 管理层值不值得托付 | 清单锚定 + 整体判断混合制（中性 6 分起始，正向锚加分，尾部风险不可见故 9.5+ 不设路径） |
| L1 | 4.6 资本回报质量 | 资本投入是否真创造价值 | **ROIC vs WACC**（EVA 经济利润思想）+ 增量 ROIC + **DuPont 三因子归因**（杠杆驱动禁入 8-10 档）+ **盈利波动性**（MSCI 增速波动口径，软锚） |
| L3 | 5.1 利润增长 | 未来 1-2 年利润怎么涨 | **基准率外部视角**（Mauboussin《The Base Rate Book》：增速均值回归、规模惩罚、分析师系统性偏高 3-5pct）+ 给区间不给点估计 |
| L3 | 5.2 项目确定性 | 增长有多少已落地 | 在建 vs 审批 vs 规划的加权确定性（按利润贡献不按个数） |
| L3 | 5.3 催化剂 | 什么事件触发重估 | 写不出月份的催化剂最高 5.9（时间可验证性约束） |

### 竞争结构分析：波特五力的完整落位

波特五力是行业结构扫描器，不是打分模型——本体系给五力各自安排了固定位置，
避免「用五力再主观打一轮分」的误用：

| 五力 | 落位 | 怎么应用 |
|------|------|---------|
| 供应商议价能力 | 4.2 产业链位置 | 上游自给率/成本曲线分位，E6 主营构成+供应商集中度佐证 |
| 购买者议价能力 | 4.2 产业链位置 | 下游定价权、客户集中度（单一客户依赖 >50% 直接压到最低档） |
| 新进入者威胁 | 4.3 护城河「复制成本」 | 每条护城河必须答出「对手要多少钱/多少年才能复制」，写不出不计数 |
| 现有竞争烈度 | 4.1 生命周期两步法 | 成熟期行业看格局集中度（CR/份额趋势），而非看增速 |
| 替代品威胁 | 4.1 必答句 + 4.3 压力测试 | 行业面：「本行业需求是否存在被替代性产品/技术整体迁移的风险」（必答，可答「威胁低+理由」，禁止省略）；公司面：替代品打过来时本公司扛不扛得住进竞争压力测试场景族 |

### 护城河：晨星五源 + 逆定位，配三硬约束防空话

4.3 的护城河枚举 = 成本/规模/牌照/技术/品牌/网络效应/转换成本（晨星五源的中文化，
有效规模并入「规模」）+ **逆定位**（Helmer《7 Powers》第八源：新商业模式使在位者
**模仿即自残**——拼多多 vs 阿里、Costco 会员制 vs 商超进场费；判据 = 答出「在位者
跟进的代价 = 牺牲现有哪块利润」，单条封顶 6-7.9 档，失效信号挂跟踪仪表盘）。

光有枚举会沦为「品牌优势」「技术领先」式空话，所以配三硬约束：

1. **复制成本约束**——写不出「对手要多少钱/多少年才能复制」的护城河不计数；
2. **定价权判据表**——凡以定价权/品牌为名的护城河，必须按交易形态给可观测判据
   （B2B 看谁发提价函、提价是否被接受；2C 品牌看提价后销量留存、终端价差、复购率；
   金融走行业附录口径），禁跨域套用；
3. **同步性检验**——凡以边际改善（毛利率回升/份额提升）作「变宽」论据的，必须拉
   ≥3 家同业同期对照，区分 α（自身壁垒延伸）与 β（行业共振）——共振不居首不计入壁垒。

另配**竞争压力测试**：评分末拍必须写「最大威胁场景 → 扛得住/警惕/扛不住（引 5-10 年
真实先例）+ 侵蚀观测信号与阈值」，给了阈值的必须挂第 14 章跟踪仪表盘——
先例 > 推演，没有阈值的威胁描述是空话。

### 财务质量：先排雷，再谈趋势

- **红旗四项清单**（先于财务健康评分执行）：利润现金含量连续 2 年 <0.7、应收/存货
  周转天数连续恶化变长 ×1.3、毛利率高出同业均值 >50% 且无业务解释——逐项三态标注
  （✓ 真通过 / ✗ 真恶化 / △ 数据不足），命中即结构化扣分，≥2 项核心结论置顶警示；
- **财报可信度评级**：应计比率 + **Beneish M-Score** 八变量 + 审计意见 → A/B/C/D，
  C 扣黄灯、D 直接红灯回避，金融/医药/地产/互联网按行业附录换替代项；
- **DuPont 归因句**：ROE 必拆净利率 × 总资产周转 × 权益乘数并标主驱动——
  杠杆撑起来的高 ROE 不许进 8-10 档（与流动性轨同一事实不重复扣分）；
- **盈利波动性**（MSCI 质量因子口径）：扣非净利同比增速的标准差，脚本算出、
  图墙角标展示、同业相对判读——本轮只展示不进定档，阈值据存量分布再定。

### 估值：以范围表达，锚不滑动

- **三情景构建**（悲观/基础/乐观）：净利区间 × PE 带，PE 用**历史时段匹配法**校准
  （找 2-3 个增速/规模/宏观相似的历史时段取 PE 区间，利润规模上量级要折价；v5.4.0 起
  校准时段 ≥2 个须标 `calib` 并写明相似度/折价理由）；三情景围绕 1-2 个关键驱动定义，
  v5.5.0 起毛利占比 ≥15% 的分部（`sensitivity_meta.coverage`）须逐条映射敏感性变量或
  写**带数字**的排除理由，缺一拒渲染；
- **估值分四件套**（脚本算，不可手填）：中枢期望收益 40% + 赔率（盈亏比）25% +
  合理倍数 25% + 税后股息 10%；
- **估值锚纪律**（v5.1.0 起，渲染器硬校验）：增量证据锁死 PE 带（无新增基本面证据
  不许移动，价格与卖方观点双向禁用）、回滚条款前置（v5.4.0 起首版同样生效、
  合理带与基础情景带双尺偏离同时看守）、锚移动上账（复盘章台账）、
  尺子一致性声明——治「估值锚跟着市价滑动」这个左侧信号的头号杀手；
- **行业方法**按附录替换：地产 NAV、创新药 rNPV、平台互联网 SOTP、金融 PB-ROE/DDM
  （v5.5.0 起 DDM 折现用的**股权成本 r** 立分型参考带，超带写理由，且 WACC 不得高于 r）；
- **预期差拆解**：无预期差 = 无超额收益——必须回答「我的模型和卖方一致预期分歧在哪」；
  逐机构分布图只照抄 E5 明细，港股无逐机构明细时调研所得须先落盘
  `_street_{code}_{date}.json` 再由 `gap_plot.source_file` 指向（v5.5.1 防手填小门）。

### 决策层：矩阵落位 + 三机制防自欺欺人

- **决策矩阵**（质量 × 估值落仓位）：重仓的唯一入口是「质量 ≥7 × 估值 ≥8」直接落位，
  任何调节链不得把轻仓推成重仓；前置两道门禁——红灯熔断、中枢为负拦截器；
- **机制一·临界档透明化**：分数距决策边界 ≤0.3 → 仓位按相邻两档孰低执行 + 升档路径
  挂跟踪仪表盘（「错过」变「推迟+验证路径」）；±0.3 经存量报告漂移实测校准
  （`score_drift.py`：同股两版质量分漂移 P50=0.38，收窄到 0.1 被数据否定）；
- **机制二·乐观税**：基础情景净利超出卖方一致预期 15% → 中枢分封顶 6，
  唯一解封路径是预期差评为 A 档（点名卖方假设+证伪理由）——「乐观可以，先掏证据」；
- **机制三·赔率 ∞ 分级保送**：悲观下限必须有证据地板——净现金硬地板全额待遇，
  保底分红软地板减半，无证据拒渲染。

### 风险层与回测

红黄灯双层（红灯=财务造假/立案/主营不可逆衰退直接熔断；黄灯单项 ≤1 累计 ≤2 扣分），
**损失预演**（premortem：「假设两年后这笔投资亏 30%，最可能的故事是什么」三联卡）；
同股再分析自动进**回测模式**：锚移动台账先审锚再审盈亏，复盘结论反哺评分纪律；
v5.5.1 起 `prev.charts` 记上版图形事实（逐机构图/财务面板数/预测年数/PE 历史带），
本版比上版减配即逐项告警——静默减配必须换成复盘章里写明理由。

### 明确不引的框架（备查，防重复调研）

Altman Z-Score（1960s 美国制造业建模，金融与新兴市场失真，偿债风险已有红灯+流动性轨
覆盖）、VRIO（「难模仿」即复制成本，增量为零）、神奇公式（ROC 已由 4.6 覆盖，
收益率侧估值轨更细）、EVA（本质即 ROIC−WACC，只作话术不作机制）、治理评级指数
（不如 4.5 清单锚定制细）。**Piotroski F-Score / Mohanram G-Score 已立项待讨论**
（1D 趋势轨机械化清单，见最新 handoff 结转章节）。

## 使用办法

### 安装

将 `stock-deep-analysis/` 目录放入技能目录：

- 用户级：`~/.agents/skills/` 或 `~/.zcode/skills/`
- 项目级：`<project>/.agents/skills/`

依赖：Python 3.8+、curl（Windows 10+ 自带）。tushare token 可选
（`TUSHARE_TOKEN` 环境变量自动发现；无 token 自动走东方财富公开接口）。

### 触发

对模型说「深度分析 600989」「给腾讯写一份研究报告」即可。首次分析走全流程；
同股再分析自动进入回测模式（见下）。

### 工作流四步

```bash
# 1. 一键取数（tushare 优先、东财兜底；A 股 6 位代码、港股 5 位代码自动识别）
python "<技能目录>/scripts/em_fetch.py" 600989 --peers=600309,002001

# 2-3. 模型分析打分（评分锚 references/scoring.md）→ 写 fill JSON（契约 references/fill-schema.md）

# 4. 渲染（评分/图形/校验/命名全由脚本完成；--check 为只预检不渲染）
python "<技能目录>/scripts/render_report.py" "_fill_600989.json"
```

### 回测模式（同股再分析）

```bash
python "<技能目录>/scripts/extract_review.py" --find 600989
python "<技能目录>/scripts/extract_review.py" --find 600989.SH --dir "D:\个股深度分析"
```

脚本递归扫描 `--dir` 目录（默认当前目录）：代码自动归一（`600989` / `600989.SH` / `600989.BJ` /
`sh600989` / `bj920982` 等价）；
文件名匹配 + 渲染器生成标记验证 + 取日期最新——找到旧报告即进入
回测模式（先独立取数打分、再读旧报告、全量重写、最后新旧对比），并直接输出 prev
锚点与旧三情景假设（fill 的 `prev.scenarios` 照抄后者，是锚移动台账与 PE 带移动
校验的共同数据源——估值锚纪律见上节）。手写绕行的 HTML 无生成标记，不会误触发。

### 校准工具

```bash
python "<技能目录>/scripts/score_calibration.py"   # 存量报告三轨分 vs 报告日后实际收益（分桶统计）
python "<技能目录>/scripts/score_drift.py"         # 同股相邻两版分数漂移分布（机制一临界宽度校准）
python "<技能目录>/scripts/monthly_checkup.py"     # 月度体检：到期复盘提醒 + 校准复跑
```

### 报告结构

固定 14 章：1 核心结论 ｜ 2 关键利润驱动 ｜ 3 最新报告期透视（条件，最新期是年报时整章消失）｜
4 公司本质 ｜ 5 未来预期 ｜ 6 风险评估（红/黄灯）｜ 7 质量分汇总（脚本生成）｜ 8 估值与安全边际 ｜
9 预期差拆解 ｜ 10 同业对比 ｜ 11 周期规律（条件）｜ 12 仓位与时机决策 ｜ 13 回测复盘（条件）｜ 14 跟踪仪表盘。

## 测试与自检

`scripts/` 下测试全部离线可跑（无网络依赖）。统一入口（v4.10.2 起全量 pytest 收集）：

```bash
python -m pytest scripts/ -q    # 全部回归（门禁/图表/端到端/golden/em_fetch/校准/体检等）
```

也可逐文件直跑：

```bash
cd scripts
python -m pytest test_render_gate.py test_render_charts.py test_render_e2e.py  # 渲染门禁/图表/端到端
python test_em_fetch.py         # 市场映射 / 闰日 / 同比文字化 / 429 硬停
python test_extract_review.py   # 回测触发判定 / 锚点提取
python test_mcap_mode.py        # 市值口径渲染
python test_golden.py           # 渲染器端到端 golden 快照（minimal/full/mcap 三份主干 fill + 报告期四态，产物与入库快照逐字节比对）
python test_calibration.py      # score_calibration 纯函数回归（文件名解析 / 分桶边界 / 同股去重）
python test_monthly_checkup.py  # monthly_checkup 月度体检回归（scan_reports 合并口径 / --disclosure 市场映射）
python test_deploy_meta.py      # 部署元数据守卫（deploy.ps1 排除清单 / UTF-8 BOM 断言 / 超长行闸扫描行为）
python test_visual_check.py     # visual_check 视觉审计降级路径（无浏览器跳过 / 坏 --chrome 路径）
python test_score_drift.py      # score_drift 分数漂移回归（_pctile / 配对与跨代隔离）
```
