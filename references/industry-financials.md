# 金融行业附录（银行 / 保险 / 券商）

> 银行、保险、券商的会计体系与估值方法和一般工商业有本质区别——资产负债是"经营原料"而非
> "经营结果"，利润高度依赖杠杆、监管与市场。**本附录用于替换通用口径**：
> 1D 盈利质量红旗清单、1D 财务体检表、估值方法、Phase 0 关键驱动识别。
> 触发：分型为「稳定价值/金融」且公司属于银行/保险/证券时，本附录优先级高于 `scoring.md`
> 的通用口径。券商与银行保险共用「金融子类」的 L1 权重浮动（**唯一一套，唯一出处在本文件**：
> 1A 6%、1B 8%、1C 18%、1D 22%、1E 24%、1F 22%，合计 100%——1D 上浮因资产质量/偿付能力
> 是金融的生死维度；1F 略降因 ROIC 口径对高杠杆金融适用性弱于工商业。
> `scoring.md` 的「稳定价值（非金融）」行不适用于金融股）。

## 通用原则（三条，先读）

1. **利润不是首要 KPI**。银行/保险/券商的当期净利润受拨备、准备金释放、投资收益、市场行情
   影响极大，是"经营结果 + 会计选择 + 市场贝塔"的混合物。先看资产负债表质量，再看利润。
2. **杠杆是经营属性，不是风险信号**。银行负债率 90%+、保险 90%+ 是商业模式本身，不能套用
   一般工商业"负债率 >70% 扣分"的尺子。真正的风险指标是资本充足率、偿付能力、资产质量。
   同理，`scoring.md` 1D 新增的「有息负债与短债覆盖」锚点对金融股豁免——以资本充足率/
   偿付能力/净资本替代有息负债口径。
3. **估值用资产/价值锚，不用当期 PE**。银行看 P/TBV-ROTCE、保险看 P/EV、券商看 PB-band。
   当期 PE 在利润顶/底会给出完全相反的信号。
4. **3A 利润增长用正常化口径（禁用当期报表利润增幅）**。金融利润增幅很大程度是市场贝塔
   （保险投资收益、银行拨备释放、券商自营），不是经营改善——被报表增幅迷惑给高分是系统性错误。
   评分锚：**保险看 EV/NBV 增速（经营增长），银行看 PPOP 增速（拨备前利润），券商看正常化
   ROE 趋势（5 年中枢）**。例：新华 H1 报表净利 +40-60% 是权益市场给的（投资收益率 2.x%→6.6%），
   按 EV +10%/NBV +20% 的正常化经营增速评 5.5-6.5 分是合理的，不是苛刻。

## 财报可信度替代项（金融股通用 · M-Score 不适用）

金融股资产负债结构与一般工商业不同，Beneish M-Score 不适用。财报可信度评级（A/B/C/D）
改按以下替代项人工判断，评级接入规则与 `forensic-accounting.md` 第 7 节一致
（C → 黄灯 d 类至少扣 0.5；D → 红灯回避）：

| 子类 | 替代核查项 |
|------|-----------|
| 银行 | 贷款分类迁徙、重组贷款占比、拨备覆盖率逆周期变化、关注类/逾期迁徙 |
| 保险 | 准备金释放对利润贡献、金融资产 Level 3 占比、再保险安排、偿付能力充足率趋势 |
| 券商 | 自营盘风险敞口、两融/质押信用减值趋势、杠杆率/净资本、资本充足率 |

审计意见仍是三类共用的必查红灯项（供红灯 a 项判定，不再列于 1D 红旗清单）。

## 一、银行

### 1D 红旗清单替换（四项，替代现金含量/应收/存货/毛利率；审计意见属红灯 a 项，不在本表）

| 红旗项 | 口径 | 判定 |
|--------|------|------|
| 不良贷款率趋势 | 不良率 NPL ratio 连续 2 年上行且幅度 >0.3pct | → 红旗 |
| 拨备覆盖率趋势 | 拨备覆盖率 = 拨备余额 ÷ 不良余额，<150% 且持续下行 | → 红旗 |
| 关注类/逾期贷款迁徙 | 关注类占比上行、逾期 90 天以上 ÷ 不良 >1（口径异常） | → 红旗 |
| 核心一级资本充足率 | CET1 < 8.5%（系统重要性银行）或 < 监管要求+0.5pct 缓冲 | → 红旗 |

### 1D 体检表（替代 ROE 趋势/毛利率/负债率/FCF）

| 指标 | 关注点 |
|------|--------|
| NIM（净息差） | 水平 + 趋势；与同业对比；LPR 下行期的息差韧性 |
| 存款成本 / 存款 beta | 低成本活期存款占比是核心负债竞争力 |
| ROE / ROTCE | ROTCE（有形普通股资本回报）比 ROE 更准，扣掉商誉/无形资产 |
| 不良生成率 | 当期新增不良 ÷ 贷款余额，比存量不良率更前瞻 |
| 拨备前利润（PPOP） | 剔除拨备的盈利能力，判断拨备是"藏利润"还是"补窟窿" |
| CET1 / 资本充足率 | 资本内生能力 vs 分红/扩张的可持续性 |

### 估值方法

**P/TBV-ROTCE 回归**（主锚）：`合理 P/TBV ≈ (ROTCE − g) ÷ (r − g)`，g 用长期 ROE×留存率，
r 用股权成本。P/TBV 与 ROTCE 应呈正相关——高 ROTCE 配高 P/TBV 才合理，脱离 ROTCE 的
低 P/TBV 是"价值陷阱"（资产质量隐患被市场定价）。PB 分位、股息率（税后）作辅助锚。

### Phase 0 关键驱动（识别对利润弹性最大的 1-2 个变量）

NIM（±10bp 对净利息收入的影响）> 信贷增速 > 资产质量（不良生成率）> 拨备计提节奏。
三情景必须围绕 NIM 与资产质量构建，而非拍利润区间。

## 二、保险（寿险为主，财险含 combined ratio）

### 1D 红旗清单替换（四项，审计意见同属红灯 a 项）

| 红旗项 | 口径 | 判定 |
|--------|------|------|
| 偿付能力充足率 | 综合偿付能力充足率 < 120%（监管红线 100%，缓冲不足） | → 红旗 |
| 综合成本率（财险） | combined ratio > 100% 连续 2 年（承保亏损） | → 红旗 |
| 准备金充足性 | 准备金释放对利润贡献占比异常高、或准备金缺口扩大 | → 红旗 |
| 投资收益率 vs 精算假设 | 实际总投资收益率持续 < 精算假设（如 5%），利差损扩大 | → 红旗 |

### 1D 体检表

| 指标 | 关注点 |
|------|--------|
| 内含价值（EV） | 每股 EV 增长 = 价值创造的根基 |
| 新业务价值（NBV）/ VNB margin | 负债端质量；NBV 增速 vs EV 增速的剪刀差 |
| CSM（合同服务边际，IFRS17） | 未来利润的"蓄水池"，释放节奏决定利润 |
| 净投资收益率 / 总投资收益率 | 与精算假设的利差；权益仓位占比（利润弹性） |
| 偿付能力充足率 | 资本缓冲 vs 分红/扩张 |
| 资产负债久期匹配 | 利率下行期的利差损风险 |

### 估值方法

**P/EV 内含价值法**（主锚）：`P = 每股 EV × P/EV 倍数`。P/EV 倍数参照公司历史分位 + 同业
折溢价（业务规模、渠道稳定性、利润波动性决定折溢价）+ 券商目标倍数。P/EV < 0.5x 通常是
深度价值区，> 0.85x 是顶部区（历史经验）。PB-ROE 作交叉验证，当期 PE 只作情绪参照（利润
峰值 PE 会给出"假便宜"）。

### Phase 0 关键驱动

**权益市场表现**（权益仓位 × 弹性系数，第一变量）> 10 年期国债收益率（EV 假设与再投资）>
NBV 增速（负债端）> 银保/个险渠道政策。三情景围绕权益市场路径构建——保险股本质是
"权益市场看涨期权 + 高股息底仓"，命不在公司手里，在市场手里。

## 三、券商

### 1D 红旗清单替换（四项，审计意见同属红灯 a 项）

| 红旗项 | 口径 | 判定 |
|--------|------|------|
| 自营盘风险敞口 | 自营权益+固收规模 ÷ 净资产 > 100% 且集中度高 | → 红旗 |
| 净资本/风险覆盖率 | 净资本低于监管预警线、风险覆盖率持续下行 | → 红旗 |
| 信用减值趋势 | 两融/股票质押减值计提趋势恶化 | → 红旗 |
| 杠杆率 | 权益乘数（总资产 ÷ 净资产）持续上行且 > 行业均值 1.5 倍 | → 红旗 |

### 1D 体检表

| 指标 | 关注点 |
|------|--------|
| ROE（正常化） | 牛熊切换下 ROE 波动极大，看 5 年正常化 ROE |
| 经纪市占率 | 零售客户基础与佣金率趋势 |
| 自营收入占比 | 占比越高，利润越像"市场贝塔" |
| 两融余额 / 股质规模 | 信用业务风险敞口 |
| 净资本 / 资本充足 | 监管约束下的扩张能力 |

### 估值方法

**PB-band**（主锚）：券商是强周期金融，PB 在牛熊间大幅波动（牛市看 PB 上沿、熊市看破净）。
`合理 PB ≈ (正常化 ROE − g) ÷ (r − g)`，正常化 ROE 用 5 年中枢，不用当期峰值。当期 PE
完全误导（牛市利润顶 PE 最低、熊市利润底 PE 最高）。辅以 P/调整后净资产、清算价值对照。

### Phase 0 关键驱动

**市场成交额 + 两融余额**（经纪/信用收入）> 权益市场表现（自营）> IPO/再融资节奏（投行）>
政策（印花税、融券、做市）。三情景围绕成交额与权益市场路径构建。

## 数据来源提示

- A 股银行/保险/券商财务：em_fetch E3（tushare `fina_indicator` 的 `roe`、`bps`、负债类字段；
  银行用 `balancesheet` 的贷款/拨备科目；保险用专项指标需妙想 MCP `mx_ashare_finance_data` 直查）。
- 港股金融（如中国平安 H、中银香港）：妙想 `mx_hk_finance_data` 首选，字段名与 A 股不同。
- 偿付能力充足率、CET1、NBV、EV、combined ratio 等监管指标：定性搜索 + 年报/季报查证，
  em_fetch 无直接字段时标注「未获取到」或「年报查证」。
- **保险准备金（寿险责任准备金等）**：tushare `balancesheet`（`comp_type=3` 保险）有专用科目——
  `reser_une_prem`（未到期责任准备金）、`reser_outstd_claims`（未决赔款准备金）、
  `reser_lins_liab`（寿险责任准备金）、`reser_lthins_liab`（长期健康险准备金）——可算准备金余额
  与趋势，配合"准备金释放对利润贡献"的定性判断替代直接查"充足率"。**综合偿付能力充足率**是监管
  披露、不在财务报表里，只能走偿付能力报告/中保协披露的定性搜索。
